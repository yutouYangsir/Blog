## 函数的定义方法
函数的定义：
```
def 函数名(传入参数):
	函数体
	return 返回值
```

比如定义一个自我介绍的函数并调用：
```
def self_introduction(name,country,sex):  
    print(f"你们好，我是{name},我是{country}最",end='')  
    if sex == 'male':  
        print("帅气的男人，",end='')  
    elif sex == 'female':  
        print("美丽的女人，",end='')  
    else:  
        print("善良的人，",end='')  
    print("希望我们能和平相处")  
  
  
name = input("请输入您的姓名：")  
country = input("请输入您的国家：")  
sex = input("请输入您的性别：")  
self_introduction(name,country,sex)
```
函数必须先定义后调用
函数的参数和返回值如果不需要，可以省略

## 函数的参数
传入参数的功能是：在函数进行计算的时候，接收外部(调用时)提供的数据

函数的传入参数 - 参数定义
```
# 基于函数的定义方法
def 函数名(传入参数):
	函数体
	return 返回值
```
如：
```
def add(x,y)
	result = x + y
	print(f"{x}+{y}的结果是：{result}")

add(5,6)
```
实现了，每次计算的是x+y，而非固定的值
x、y的值，可以在调用函数的时候指定

- 函数定义中，提供的x和y，称之为：形式参数(形参)，表示函数声明将要使用两个参数
	- 参数之间使用都好进行分隔
- 函数调用中，提供的5和6，称之为：实际参数(实参)，表示函数执行时真正使用的参数值
	- 传入的时候，按照顺序传入数据，使用逗号分隔

## 函数的返回值
### 程序中的返回值
```
def add(a,b)
	result = a+b
	return result
	
r = add(1,2)
print(r)
```
上述代码当中
定义两数相加的函数功能。完成功能后，会将相加的结果返回给函数调用者
所以，变量r接收到了函数的执行结果

返回值，就是程序中函数完成事情后，最后给调用者的结果

### None类型
如果一个函数没有使用return语句返回数据，那么函数有返回值吗？

答案是：有

Python中有一个特殊的字面量：None，其类型是NoneType
无返回值的函数，实际上就是返回了None这个字面量

```
def test():  
    print()  
  
print(test(),type(test()))

# 运行结果


None <class 'NoneType'>
```

None作为一个特殊的字面量，用于表示：
空、无意义，其有非常多的应用场景
- 用在函数无返回值上
- 用在if判断上
	- 在if判断中，None等同于False
	- 一般用于在函数中主动返回None，配合if判断做相关处理
- 用在生命无内容的变量上
	- 定义变量，但暂时不需要变量具有具体值，可以用None来代替
	```
	# 暂不赋予变量具体值
	name = None
	```

## 函数的嵌套使用
函数嵌套就是指在一个函数的里面又调用了另外一个函数

函数A中执行到调用函数B的语句，会将函数B全部执行完成后，继续执行函数A的剩余内容

## 变量的作用域
变量的作用域指的是变量的作用范围(变量在哪里可用，在哪里不可用)
主要分为两类：局部变量和全局变量
### 局部变量
局部变量是定义在函数体内部的变量，即只在函数体内部体内部生效
```
def testA():
	num = 100
	print(num)

testA() # 100
print(num) # 报错：name 'num' is not defined
```
变量num是定义在 `testA` 函数内部的变量，在函数外部访问则立即报错

局部变量的作用：在函数体内部，临时保存数据，即当函数调用完成后，则销毁局部变量

### 全局变量
全局变量，指的是在函数体内、外都能生效的变量
思考：如果有一个数据，在函数A和函数B中都要使用，该怎么办？
答：将这个数据存储在一个全局变量里面
```
# 定义全局变量a
num = 100
def testA():
	print(num) # 访问全局变量num，并打印变量num存储的数据

def testB():
	print(num) # 访问全局变量num，并打印变量num存储的数据
	
testA() # 100
testB() # 100
```

### global关键字
思考： `testB` 函数需要修改num的值为200，如何修改程序？
```
num = 100
def testA():
	print(num)
	
def testB():
	num = 200
	print(num)

testA() # 100
testB() # 200
print(num) # 100
```
testB中的num为自己的局部变量，不影响外部的全局变量num
那假如我就是要在 testB 里面把 num 的值给修改掉，怎么办？
**global**关键字闪亮登场
使用global关键字，可以在函数内部声明变量为全局变量，如下：
```
num = 100  
def testA():  
    print(num)  
def testB():  
	# global 关键字声明num是全局变量
    global num  
    num = 200  
    print(num)  
testA()  # 100  
testB()  # 200  
print(num)  # 200
```

### 列表的下标索引
#### 下标索引
如何从列表中取出特定位置的数据呢？
我们可以使用：下标索引
列表中的每一个元素，都有其位置下标索引，从前向后的方向，从0开始，一次递增
```
# 语法：列表[下标索引]

zhangsan_list = ['张三',21,True,1.70]
print(zhangsan_list[0]) # 张三
print(zhangsan_list[1]) # 21
print(zhangsan_list[2]) # True
print(zhangsan_list[3]) # 1.70


print(zhangsan_list[4]) # 报错，超出范围IndexError: list index out of range

```

#### 反向
或者，可以反向索引，也就是从后向前：从-1开始，依次递减(-1,-2,-3)
```
zhangsan_list = ['张三',21,True,1.70]
print(zhangsan_list[-1]) # 1.70
print(zhangsan_list[-2]) # True
print(zhangsan_list[-3]) # 21
print(zhangsan_list[-4]) # 张三
```

#### 列表的遍历
既然数据容器可以存储多个元素，那么，就会有需求从容器内依次取出元素进行操作
将容器内的元素依次取出进行处理的行为，称之为：遍历、迭代

```
index = 0
while index < len(列表):
	元素 = 列表[index]
	对元素进行处理
	index += 1
```
```
for 临时变量 in 数据容器:
	对临时变量进行处理 
```

```
def list_while_func(list1):  
    index = 0  
    while index < len(list1):  
        print(str(list1[index])+" ",end='')  
        index+=1  
  
def list_for_func(list1):  
    for i in list1:  
        print(str(i)+" ",end='')  
  
  
list1 = ['yang','is','very','handsome']
```

while循环和for循环，都是循环语句，但细节不同
- 在循环控制上
	- while循环可以自定循环条件，并自行控制
	- for循环不可以自定循环条件，只可以一个个从容器中取出数据
- 在无线循环上
	- while循环可以通过条件控制做到无限循环
	- for循环理论上不可以，因为被遍历的容器不是无限的
- 在使用场景上
	- while循环适用于任何想要循环的场景
	- for循环适用于，遍历数据容器的场景或简单的固定次数循环场景
## 元组
列表是可以修改的
如果我想要传递的信息不可以被篡改，列表就不合适了

元组同列表一样，都是可以封装多个、不同类型的元素在内
但最大的不同点在于：
**元组一旦定义完成，就不可以修改**
所以，当我们需要在程序内封装数据，又不希望封装的数据被篡改，就需要元组了

### 定义元组
```
# 定义元组字面量
(元素,元素,......,元素)
# 定义元组变量
变量名称 = (元素,元素,......,元素)
# 定义空元组
变量名称 = ()      # 方式1
变量名称 = tuple() # 方式2
```
注意事项：
```
# 定义1个元素的元组
t2 = ('hello',)
# 注意，必须带有逗号，否则不是元组类型
```
元组也支持嵌套：
```
# 定义一个嵌套元组
t1 = (1,2,3,(4,5,6))
print(t1[-1][-1])
# 输出结果
6
```

### 元组的相关操作


| 编号  | 方法      | 作用                        |
| --- | ------- | ------------------------- |
| 1   | index() | 查找某个数据，如果数据存在返回对应的下标，否则报错 |
| 2   | count() | 统计某个数据在当前元组出现的次数          |
| 3   | len(元组) | 统计元组内的元素个数                |

```
t1 = ('yang','is','very','handsome',21,1,1,1,1.70)

print(t1.index(1)) # 结果：5

print(t1.count(1)) # 结果：3

print(len(t1)) # 结果：9
```

### 注意事项
- 不可以修改元组的内容，否则会直接报错
```
t1 = ('yang','is','very','handsome',21,1,1,1,1.70)  
  
t1[0] = 'liu'

TypeError: 'tuple' object does not support item assignment
```
- 如果元组内，嵌套了一个list，可以修改list里面的内容
```
t1 = ('yang','is','very','handsome',[21,1,1,1,1.70])  
  
t1[-1][-1] = 2.20  
print(t1)

# 输出结果
('yang', 'is', 'very', 'handsome', [21, 1, 1, 1, 2.2])
```
## 字符串
尽管字符串看起来不像列表、元组那样，一看就是存放了许多数据的容器
但不可否认的是，字符串也是数据容器大家族的一员

字符串就是字符的容器，一个字符串可以存放任意数量的字符，如：`yang`
### 字符串的下标索引
和其他容器一样，字符串也可以通过下标进行访问
- 从前往后，下标从0开始
- 从后往前，下标从-1开始
```
# 通过下标获取特定位置字符
name = 'yangsir'
print(name[0]) # y
print(name[-1]) # r
```
同元组一样，字符串是一个：无法修改的数据容器

## 数据容器的切片
### 序列
序列是指：内容连续、有序，可使用下标索引的一类数据容器
列表、元组、字符串，均可以视为序列
### 切片
切片是指：从一个序列中取出一个子序列

语法：序列\[起始下标:结束下标:步长]
表示从序列中，从指定位置开始，依次取出元素，到指定位置结束，得到一个新序列：
- 起始下标表示从何处开始，可以留空，留空视作从头开始
- 结束下标（不含）表示何处结束，可以留空，留空视作截取到结尾
- 步长表示，依次取元素的间隔
	- 步长1表示，一个个取元素
	- 步长2表示，每次跳过1个元素取
	- 步长N表示，每次跳过N-1个元素取
	- 步长为负数表示，反向取（注意，起始下标和结束下标也要反向标记）

**小问题**
为什么集合是没有顺序的，而这里的每次输出都是固定的呢？
```
**1. 小整数（特别是 1-5）的“内存驻留”机制**  
在 Python 中，整数 `1` 到 `256` 是预先创建好的单例对象。当你创建集合时，它们被添加到哈希表中的顺序，恰好依赖于这些整数对象的哈希值（整数的哈希值就是它本身）。对于 `1,2,3,4,5` 这几个连续的小整数，它们的哈希值在底层数组中的映射位置恰好按顺序排列，所以遍历时看起来是排序的。

**2. 集合的打印顺序取决于“哈希表存储位置”**  
集合内部是一个稀疏数组（哈希表）。当你遍历集合时，Python 是按照哈希表底层数组的**索引顺序**来输出的，而不是按照插入顺序。  
对于小整数，计算出的“槽位”恰好是按大小排列的，所以打印出来是 `{1, 2, 3, 4, 5}`。但这只是该特定数据在特定 Python 版本（如 CPython 3.6+）下的实现细节。
```
- 统计集合元素数量
