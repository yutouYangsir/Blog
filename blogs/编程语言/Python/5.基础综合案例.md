# json数据格式
## 介绍
- JSON是一种轻量级的数据交互模式
- JSON本质上是一种带有特定格式的字符串
- 主要功能：json就是一种在各种编程语言中流通的数据格式，负责不同编程语言中的数据传递和交互

- 各种编程语言存储数据的容器不尽相同，在Python中有字典dict这样的数据类型，而其他语言可能没有对应的字典
为了让不同的语言都能够相互通用互相传递数据，JSON就是一种非常良好的中转数据格式

## json格式数据转化
- json格式的数据要求很严格
```
# json数据可以是:
{'name':'admin','age':18}

# 也可以是:
[{'name':'admin','age':18},{'name':'root','age':20}]
# 可以是列表，但是列表中嵌套的必须是字典
```

可以说json就是把Python中的字典转换为字符串

## python数据和json数据的相互转化
```
import json  
  
data = [{'name':'yang','age':21},  
{'name':'wang','age':26}]  
  
# 通过json.dumps()方法把python数据转换为了json数据  
data = json.dumps(data)  
print(data,type(data))  
  
# 通过json.loads()方法把json数据转化为了python数据  
data = json.loads(data)  
print(data,type(data))


# 输出结果
[{"name": "yang", "age": 21}, {"name": "wang", "age": 26}] <class 'str'>
[{'name': 'yang', 'age': 21}, {'name': 'wang', 'age': 26}] <class 'list'>
```
编码问题：
```
data = [{'name':'杨','age':21},  
{'name':'王','age':26}]  
  
# 通过json.dumps()方法把python数据转换为了json数据  
data = json.dumps(data)  
print(data,type(data))

# 输出结果
[{"name": "\u6768", "age": 21}, {"name": "\u738b", "age": 26}] <class 'str'>
```
中文在转化时，会涉及编码问题
```
data = json.dumps(data,ensure_ascii=False) 
# 这样子就可以了 
```

## `pyecharts`入门
```
# 导包
from pyecharts.charts import Line  
# 创建一个折线图对象
line = Line()  
# 给折线图对象添加x轴的数据
line.add_xaxis(['yang','zhang','zhao'])
# 给折线图对象添加y轴的数据  
line.add_yaxis('颜值',[100,30,20])
# 通过render方法，将代码生成为图像  
line.render()
```
当我们运行`line = Line()`,本质上是创建了一个空的二维坐标系，也就是相当于一个空的x轴和y轴
当调用`line.add_xaxis()`时，就得到了x轴的数据
当调用`line.add_yaxis()`时，就得到了y轴的数据
最终通过`line.render`行程基础折线图

- 系列配置选项
### set_global_opts方法
全局配置选项可以通过`set_global_opts`方法来进行配置，相应的选项和选项的功能如下
![[imgs/Pasted image 20260917140206.png]]

```
# 设置全局配置项 通过set_global_opts来设置  
line.set_global_opts(  
    title_opts=TitleOpts(title='谁是最帅的人')  
)
# 可以按住`Ctrl`+`P`查看可以传的参数，选择通过关键字传参
```

```
# 导包  
from pyecharts.charts import Line  
from pyecharts.options import TitleOpts,LegendOpts,ToolboxOpts,VisualMapOpts  
# 创建一个折线图对象  
line = Line()  
# 给折线图对象添加x轴的数据  
line.add_xaxis(['yang','zhang','zhao'])  
# 给折线图对象添加y轴的数据  
line.add_yaxis('颜值',[100,30,20],encode='utf-8')  
  
# 设置全局配置项 通过set_global_opts来设置  
line.set_global_opts(  
    title_opts=TitleOpts(True,title='谁是最帅的人',pos_left='center',pos_bottom='90%'),  
    legend_opts=LegendOpts(is_show=True,pos_left='10%',pos_bottom='90%'),  
    toolbox_opts=ToolboxOpts(is_show=True),  
    visualmap_opts=VisualMapOpts(is_show=True)  
)  
  
# 通过render方法，将代码生成为图像  
line.render()
```

我们可以看到，在原本的数据中，并不是干净的json格式，我们需要做一些简单的处理
```
# 处理数据  
f_us = open('折线图数据/美国.txt','r',encoding='utf-8')  
us_data = f_us.read() # 读取到美国的全部内容  
# 去掉不合JSON规范的开头和结尾  
us_data = us_data[us_data.index('(')+1:us_data.rindex(')')]
```
通过观察发现‘()’里面就是干净的json格式，所以通过index正向索引和rindex反向索引，来提取出干净的json

再然后，我们呢要把json格式转换为python的数据，也就是我们的字典
```

### 日本、印度
基本差不多
复制粘贴搞定

```
# 导包  
import json  
from pyecharts.charts import Line  
# 处理数据  
f_us = open('折线图数据/美国.txt','r',encoding='utf-8')  
f_jp = open('折线图数据/日本.txt','r',encoding='utf-8')  
f_in = open('折线图数据/印度.txt','r',encoding='utf-8')  
us_data = f_us.read() # 读取到美国的全部内容  
jp_data = f_jp.read()  
in_data = f_in.read()  
# 去掉不合JSON规范的开头和结尾  
us_data = us_data[us_data.index('(')+1:us_data.rindex(')')]  
jp_data = jp_data[jp_data.index('(')+1:jp_data.rindex(')')]  
in_data = in_data[in_data.index('(')+1:in_data.rindex(')')]  
# JSON转Python字典  
us_dict = json.loads(us_data)  
jp_dict = json.loads(jp_data)  
in_dict = json.loads(in_data)  
# 获取trend key  
us_trend_data = us_dict['data'][0]['trend']  
jp_trend_data = jp_dict['data'][0]['trend']  
in_trend_data = in_dict['data'][0]['trend']  
# 获取日期数据，用于x轴，取2020年（到314下标结束）  
line = Line()  
line.add_xaxis(us_trend_data['updateDate'][0:314])  
  
# 获取确认数据，用于y轴，取2020年（到314下标结束）  
line.add_yaxis('美国确诊人数',us_trend_data['list'][0]['data'][0:314])  
line.add_yaxis('日本确诊人数',jp_trend_data['list'][0]['data'][0:314])  
line.add_yaxis('印度确诊人数',in_trend_data['list'][0]['data'][0:314])  
# 生成图表  
line.render()
# 关闭文件
f_us.close()  
f_jp.close()  
f_in.close()
```

# 地图
```
import json  
from pyecharts.charts import Map  
from pyecharts.options import *  
f = open('./地图数据/疫情.txt','r',encoding='utf-8')  
data = f.read()  
f.close()  
data = json.loads(data)  
province = data['areaTree'][0]['children']  
data_list = []  
for i in province:  
    if i['name'] in ('北京' , '上海' ,'天津' , '重庆'):  
        province_name = f"{i['name']}市"  
    elif i['name'] in ('香港' , '澳门'):  
        province_name = f"{i['name']}特别行政区"  
    elif i['name'] == '新疆':  
        province_name = f"{i['name']}维吾尔自治区"  
    elif i['name'] in ('西藏','内蒙古'):  
        province_name = f"{i['name']}自治区"  
    elif i['name'] == '广西':  
        province_name = f"{i['name']}壮族自治区"  
    elif i['name'] == '宁夏':  
        province_name = f"{i['name']}回族自治区"  
    else:  
        province_name = f"{i['name']}省"  
    print(province_name)  
    province_confirm = i['total']['confirm']  
    province_data = (province_name,province_confirm)  
    data_list.append(province_data)  
  
map = Map()  
map.add('各省份确诊人数',data_list,'china')  
map.set_global_opts(  
    title_opts=TitleOpts(title='全国疫情地图'),  
    visualmap_opts = VisualMapOpts(  
        is_show=True,  
        is_piecewise=True,  
        pieces = [  
            {"min": 1, "max": 99, "label": "1~99人", "color": "#CCFFFF"},  
            {"min": 100, "max": 999, "label": "100~9999人", "color": "#FFFF99"},  
            {"min": 1000,"max": 4999,"label":"1000~4999人", "color": "#FF9966"},  
            {"min": 5000, "max": 9999,"label": "5000~9999人", "color": "#FF6666"},  
            {"min": 10000, "max": 99999, "label": "10000~99999人", "color": "#CC3333"},  
            {"min": 100000,"label": "100000+人", "color": "#990033"},  
        ]  
    ),  
  
)  
map.render('map.html')
