# 闭包
## 作用
在之前的学习中，我们会发现：
当调用完函数后，函数内定义的变量就销毁了，但有时需要保存函数内的这个变量，并在这个变量的基础上完成一系列的操作
比如：每次在这个变量的基础上和其他数字进行求和运算，该怎么办呢？

闭包！

闭包可以保存函数内的变量，而不会随着调用完函数而被销毁
## 语法
在函数嵌套的前提下，内部函数使用了外部函数的变量，并且外部函数返回了内部函数，
这种：**使用外部函数变量和内部函数**称为闭包
```
# 外部函数
def 外部函数名(外部参数):
	# 内部函数
	def 内部函数名(内部参数):
		...[使用外部函数的变量]
	return 内部函数名 # 闭包 
```
注意：
```
return 内部函数名()
返回的是内部函数执行的结果
```
```
return 内部函数
返回的是内部的这个函数对象
```
```
def get_sum(a,b):
	return a+b
	
num = get_sum(1,2) # 这是调用函数
my_sum = get_sum   # 这是直接将函数赋给my_sum
```


闭包的构成条件：
1. 有嵌套：在函数嵌套的前提下
2. 有引用：内部函数使用了外部函数的变量
3. 有返回：外部函数返回了内部函数

### 案例分析
```
定义一个用于求和的闭包
其中，外部函数有参数num1，内部函数有参数num2，然后调用，并用于求解两数之和，观察结果
``` 

```
def func_out(num1):  
    def func_inner(num2):  
        num = num1 + num2  
        print(num)  
    return func_inner  
f = func_out(1)  
f(2)
# 输出结果
3
```
## nonlocal关键字
global:声明全局变量
nonlocal:声明能够让内部函数去修改外部函数的变量
### 案例分析
```
编写一个闭包，让内部函数去访问外部函数内的参数a = 100，观察效果
```

```
def func_out():  
    a = 100  
    def func_inner():  
        nonlocal a  
        a += 1  
        print(a)  
    return func_inner  
f = func_out()  
f()  
f()  
f()  
f()

# 输出结果
101
102
103
104
```

# 装饰器
## 作用
在不改变原有函数功能的基础下，给原有函数增加额外功能
装饰器本质上就是一个闭包函数

## 构成条件
装饰器的构成条件
1. 有嵌套：在函数嵌套(函数里面再定义函数)的前提下
2. 有引用：内部函数使用了外部函数的变量(还包括外部函数的参数)
3. 有返回：外部函数返回了内部函数名
4. 有额外功能：给需要装饰的原有函数增加额外功能

## 语法
### 方式1
传统方式：
```
变量名 = 装饰器名(原有函数名)
	变量名()
```


### 方式2
语法糖.
在要被装饰的原函数上，直接写 *@装饰器名*，之后直接调用原函数即可

### 案例分析
```
例如，发表评论前，都是需要先登陆的
先定义有发表评论的功能函数，然后再不改变原有函数的基础上，需要提示用户要先登录
```

```
"""  
案例：装饰器入门  
装饰器介绍：  
    概述/作用：  
        它的本质上是一个闭包函数，目的是，在不改变原有函数的基础上，对其功能做增强        大白话：装修队在不改变房屋结构的情况下，对房屋做装饰(功能增强)  
    前提条件：  
        1. 有嵌套  
        2. 有引用  
        3. 有返回  
        4. 有额外功能  
"""  
# 定义外部函数，形参列表接收 要被装饰的函数名(对象)  
def check_login(fn_name): # fn_name: 被装饰的函数名(对象)  
    # 定义函数内部函数  
    def fn_inner():  
        # 额外功能  
        print('校验登录...')  
        print('登陆成功!')  
        # 访问原函数，即:外部函数的引用  
        fn_name()  
    # 返回内部函数对象  
    return fn_inner  
  
  
# 定义函数，表示发表评论和充值功能  
def comment():  
    print('发表评论')  
def payment():  
    print('正在充值...')  
  
```

# 装饰器的使用
## 函数的分类
- 无参无返回值的函数
		定义：def 函数名():...
		调用：函数名()
- 有参无返回值的函数
		定义：def 函数名(形参):...
		调用：函数名(实参)
- 无参有返回值的函数
		定义：def 函数名():...  return 返回值
		调用：用变量接收返回值 = 函数名()
- 有参有返回值的函数
		定义：def 函数名(形参):...  return 返回值
		调用：用变量接收返回值 = 函数名(实参)

## 案例分析
### 无参无返回值
```
"""  
案例: 装饰器装饰  
细节：  
    装饰器内部函数格式 要和 被装饰的原函数 保持一致    即: 原函数是无参无返回的，则 装饰器的内部函数也必须是 无参无返回的  
        ......"""

def loading(fn_name):  
    def fn_inner():  
        print('正在努力加载中哦...')  
        time.sleep(3)  
        fn_name()  
    return fn_inner  
  
@loading  
def get_sum():

    num2 = int(input('请输入第二个数字:'))  
    print(f'{num1}+{num2}={num1 + num2}')  
  
  
if __name__ == '__main__':  
    get_sum()
```

### 可变参数
需求：
```
定义一个可以计算多个数据和多个字典value值之和的函数，并调用。
在原有函数的计算结果之前，加一个友好提示（不改变源码）：正在努力计算中...
```

```
"""  
案例: 装饰器装饰  
细节：  
    装饰器内部函数格式 要和 被装饰的原函数 保持一致    即: 原函数是无参无返回的，则 装饰器的内部函数也必须是 无参无返回的  
        ......"""  
# 需求: 定义一个可以计算多个数据和字典value值的函数，并给友好提示  
  
import time  
  
def loading(fn_name):  
    def inner(*args, **kwargs):  
        print('正在努力计算中...')  
        time.sleep(3)  
        return fn_name(*args, **kwargs)  
    return inner  
  
@loading  
def get_sum(*args,**kwargs):  
    """  
    该函数用于计算 数字元组 和 字典value值 之和  
    :param args: 数字元组 ——> 接收所有的位置参数，封装到 元组  
    :param kwargs: 字典,键是字符串,值是数字 ——> 接收所有的关键字参数,封装到字典  
    :return:结果之和  
    """    # 定义求和变量  
    # sum = 0  
    # for item in args:    
	#    sum += item    
    # for v in kwargs.values():    
    #    sum += v    # return sum    
    return sum(args)+sum(kwargs.values())  
  
if __name__ == '__main__':  
    print(get_sum(1,2,3,a=1,b=2,c=3))
```

# 多个装饰器的使用
多个装饰器的装饰过程是：
离函数最近的装饰器先装饰，然后外面的装饰器在进行装饰，由内到外的装饰过程

```
import time,random  
  
  
def check_login(fn_name):  
    def inner():  
        print('正在检验是否登录',end='')  
        loading()  
        print('您已登录!即将发表评论',end='')  
        loading()  
        fn_name()  
    return inner  
  
def check_code(fn_name):  
    def inner():  
        print('正在检验验证码是否正确', end='')  
        loading()  
        print('验证码ok,即将发表评论', end='')  
        loading()  
        fn_name()  
    return inner  
  
def comment():  
    print('发表评论成功')  
  
def loading():  
    time.sleep(random.randint(1,3))  
    print('.',end='')  
    time.sleep(random.randint(1,3))  
    print('.',end='')  
    time.sleep(random.randint(1,3))  
    print('.')  
  
if __name__ == '__main__':  
    comment = check_code(comment)  
    comment = check_login(comment)  
    comment()
```

就比如在这个代码当中
我们需要先校验登录，再校验验证码
使用语法糖的话
```
@check_login  
@check_code  
def comment():  
    print('发表评论成功')
```
就是login在上，code在下
越是靠近原函数,就越是在内部

但是使用传统的方法:
```
    comment = check_code(comment)  
    comment = check_login(comment)  
```
code在上,login在下,为什么呢?
因为code先被装饰,就更靠近原函数,越靠近就越是在内部
login后装饰,那么就在外部,懂了吧

# 带有参数的装饰器
需求:定义一个技能装饰减法运算,又能装饰加法运算的装饰器,即带有参数的装饰器

==以下是错误代码:==
```
# 装饰器
# 外部函数
def decorator(fn,flag):
	def inner(num1,num2):
		
		if flag == '+':
			print('--正在努力加法运算--')
		elif flag == '-':
			print('--正在努力减法运算--')
		else:
			print('未知符号')
		result = fn(num1,num2)
		return result
	return inner
```

```
# 被带有参数的装饰器装饰的函数
@decorator('+')
def add(a,b):
	result = a + b
	return result
	
@decorator('-')
def subtract(a,b):
	if a>b:
		result = a - b
	else: 
		result = b - a
	return result

# 执行函数
if __name__ == '__main__':
	result = add(1,2)
	print(result)
```

==使用带有参数的装饰器,其实是在装饰器外面又包裹了一个函数,使用该函数接收参数,返回装饰器==
修改后的装饰器:
```
# 定义装饰器
def logging(flag):
	# 外部函数
	def decorator(fn):
		def inner(num1,num2):
			# 判断流程
			if flag == '+':  
			    print('--正在努力加法运算--')  
			elif flag == '-':  
			    print('--正在努力减法运算--')  
			else:  
			    print('未知符号')
			result = fn(num1, num2)  
			return result
		# 返回内部函数
		return inner
	# 返回装饰器
	return decorator
```
