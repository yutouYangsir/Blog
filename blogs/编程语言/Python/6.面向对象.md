# 初识对象
## 介绍
使用变量记录数据有时候太乱了。
我们需要一套标准
如果程序中也和生活中一样
- 可以设计表格
- 可以将设计的表格打印出来
- 可以将打印好的表格供人填写内容
那么数据的组织就非常方便了
可不可以呢？
当然可以！

在程序中是可以做到和生活中那样，设计表格、生产表格、填写表格的组织形式的。
1. 在程序中设计表格，我们称之为：**设计类(class)**
```
class Student:
	name = None  # 记录学生姓名
```
2. 在程序中打印生产表格，我们称之为：**创建对象**
```
# 基于创建对象
stu_1 = Student()
stu_2 = Student()
```
3. 在程序中填写表格，我们称之为：**对象属性赋值**
```
stu_1.name = 'yang' # 为学生1对象赋予对象属性值
stu_2.name = 'wang' # 为学生2对象赋予对象属性值
```
## 类的定义和使用
我们来看看类的使用语法：
```
class 类名称:
	类的属性
	
	类的行为
```
- class是关键字，表示要定义类了
- 类的属性，即定义在类中的变量
- 类的行为，即定义在类中的函数

创建类对象的语法：
```
对象 = 类名称()
```
## 成员方法
什么是类的行为（方法）呢？
```
class Student:
	name = None
	age = None
	
	def say_hi(self):
		print(f"Hello呀,我是{self.name}")
```
创建对象、赋值、调用方法：
```
stu_1 = Student()  
stu_1.name = '杨'  
stu_1.say_hi()
# 输出结果
Hello呀,我是杨
```
可以看出，类中：
- 不仅可以定义属性用来记录数据
- 也可以定义函数，用来记录行为
其中：
- 类中定义的属性(变量)，我们称之为：**成员变量**
- 类中定义的行为(函数)，我们称之为：**成员方法**
从此开始，定义在类内部的函数，就称之为**方法**

### 成员方法的定义语法
在类中定义成员方法和定义函数基本一致，但仍有细微区别：
```
def 方法名(self,形参1,......,形参N):
	方法体
```
可以看到，在方法定义的参数列表中，有一个：`self`关键字
`self`关键字是成员方法定义的时候，必须填写的
- 它用来表示类对象自身的意思
- 当我们使用类对象调用方法时，self会自动被python传入
- 在方法内部，想要访问类的成员变量，必须使用self

注意事项：
`self`关键字，尽管在参数列表中，但是传参的时候可以忽略它
如：
```
class Student:  
    name = None  
    age = None  
  
    def say_hi(self):  
        print(f"Hello呀,我是{self.name}")  
    def say_sth(self,msg):  
        print(f'{self.name}说:{msg}')  
stu_1 = Student()  
stu_1.name = '杨'  
stu_1.say_hi()               
# 调用的时候无需传参
stu_1.say_sth('我是这条街最靓的仔')
# 调用的时候需要传msg参数 


# 输出结果
Hello呀,我是杨
杨说:我是这条街最靓的仔
```
可以看到，在传入参数的时候，`self`是透明的，可以不用理会它

## 构造方法
```
class Student:  
    name = None # 姓名  
    age = None  # 年龄  
    tel = None  # 电话号码  

stu_1 = Student()  
stu_1.name = '张强'  
stu_1.age = 17  
stu_1.tel = '19500001234'
```
在这样子的代码当中，我们可以发现，为对象的属性赋值，需要一行行一次运行，略显繁琐
为了解决这个问题，**构造方法**登场了

Python类可以使用：`__init__()`方法，称之为构造方法
可以实现：
- 在创建类对象(构造类)的时候，会自动执行
- 在创建类对象(构造类)的时候，将传入参数自动传递给`__init__`方法使用
如下：
```
class Student:  
    name = None # 姓名  
    age = None  # 年龄  
    tel = None  # 电话号码  
    def __init__(self,name,age,tel):  
        self.name = name  
        self.age = age  
        self.tel = tel  
    stu_1 = Student('张强',17,'19500001234')
```
其实：
```
	name = None # 姓名  
    age = None  # 年龄  
    tel = None  # 电话号码 
```
有了构造方法，这三行代码就可以省略了
```
        self.name = name  
        self.age = age  
        self.tel = tel
```
构造方法内部的三个赋值，就算是完成成员变量的定义了
## 其他内置方法
刚刚的`__init__`构造方法，是Python类内置的方法之一
这些内置的类方法，各有各自的特殊功能
这些内置方法，我们称之为：魔术方法
魔术方法：
- `__init__`：构造方法
- `__str__`：字符串方法
- `__lt__`：小于、大于符号比较
- `__le__`：小于等于、大于等于符号比较
- `__eq__`：\==符号比较
- 等等......
### `__str__`字符串方法
  ```
  class Student:  
    def __init__(self,name,age):  
        self.name = name  
        self.age = age  
  
stu_1 = Student('张强',17)  
print(stu_1)  
print(str(stu_1))
  ```
这样子的输出结果都是内存地址
```
<__main__.Student object at 0x00000218EC0DDA90>
<__main__.Student object at 0x00000218EC0DDA90>
```
我们需要通过`__str__`方法，控制类转换为字符串的行为
```
class Student:  
    def __init__(self,name,age):  
        self.name = name  
        self.age = age  
    def __str__(self):  
        return f'Student类对象，name={self.name},age={self.age}'  
stu_1 = Student('张强',17)  
print(stu_1)  
print(str(stu_1))
```
输出结果就变为在`__str__`中定义的内容
```
Student类对象，name=张强,age=17
Student类对象，name=张强,age=17
```
### `__lt__`小于符号比较方法
当我们需要对象之间的比较
比如：
```
class Student:  
    def __init__(self,name,age):  
        self.name = name  
        self.age = age  
  
stu_1 = Student('张强',17)  
stu_2 = Student('王麻子',19)  
print(stu_1<stu_2)
```
这样子会直接报错，需要这样子：
```
print(stu_1.age<stu_2.age)
# 输出结果
True
```
直接对2个对象进行比较是不可以的，但是在类中实现`__lt__`方法（lt的意思是 less than ），即可同时完成：小于符号和大于符号2种比较
```
class Student:  
    def __init__(self,name,age):  
        self.name = name  
        self.age = age  
    def __lt__(self, other):  
        return self.age < other.age  
  
stu_1 = Student('张强',17)  
stu_2 = Student('王麻子',19)  
print(stu_1<stu_2)

# 输出结果
True
```
这不就没毛病了嘛
### `__le__`小于等于符号比较方法
魔术方法：`__le__`可用于：`<=`、`>=`两种比较运算符上
```
    def __le__(self, other):  
        return self.age <= other.age 
```
### `__eq__`比较运算符实现方法
- 不实现`__eq__`方法，对象之间可以比较，但是是比较内存地址，也即是：不同对象\==比较一定是False结果
- 实现了`__eq__`方法，就可以按照自己的想法来决定2个对象是否相等了
```
    def __eq__(self, other):  
        return self.age == other.age 
```
## 面向对象的三大特性
面向对象编程，是许多编程语言都支持的一种编程思想。
简单理解就是：基于模板(类)去创建实体(对象)，使用对象完成开发

面向对象包含3大主要特性：
- 封装
- 继承
- 多态
### 封装
封装表示的是，将现实世界事物的:
- 属性
- 行为
封装到类中，描述为
- 成员变量
- 成员方法
从而完成程序对现实世界事物的描述
#### 私有变量和属性
现实世界中的事物，有属性和行为
但是不代表这些属性和行为都是开放给用户使用的

以手机举例子：
对用户开放的：
- 属性
	- 序列号
	- 品牌、型号
	- 长宽高
- 行为
	- 上网
	- 拍照
	- 通话
对用户隐藏的：
- 属性
	- 运行电压
	- 驱动信息
- 行为
	- 程序调度
	- 内存管理

既然现实事物有不公开的属性和行为，那么作为现实事物在程序中映射的类，也应该支持

类中提供了私有成员的形式来支持
- 私有成员变量
- 私有成员方法
####  定义
定义私有成员的方式非常简单，只需要：
- 私有成员变量：变量名以`__`开头
- 私有成员方法：方法名以`__`开头
即可完成私有成员的设置
如下：
```
class Student:  
    name = None  
    age = None  
    __tel = None  
    def __my_name(self):  
        print(f'我叫{self.name}')
```
`__tel`就是私有成员变量
`__my_name`就是私有成员方法
```
stu_1.__tel = '19500001234'  # 不报错，执行不是预期，而是新创建了一个属性
stu_1.__my_name() # 报错
```

私有变量无法赋值，也无法获取值
私有方法也无法被直接调用

```

----
Python 没有真正的私有，只有**约定 + 名称改编**。

|写法|名称|含义|外部能否访问|
|---|---|---|---|
|`name`|公有|公开接口|✅ 能|
|`_name`|单下划线|约定内部用（弱私有）|✅ 能，但不建议|
|`__name`|双下划线|触发名称改编（强约定）|⚠️ 能，但要绕|
|`__name__`|双下划线包围|魔法方法/系统保留|✅ 能|

**关键规则**：以 `__` 开头、且**不以 `__` 结尾**的标识符，会被改编为 `_类名__标识符`

> **Python 的私有 = 命名约定 + 名称改编，目的是表达意图、降低耦合、防止误用，而不是物理上禁止访问。**

| 想做的事 | 推荐做法 |
|---------|---------|
| 表示“这是内部细节” | 用 `__xxx` |
| 表示“约定别碰” | 用 `_xxx` |
| 对外提供受控访问 | 用 `@property` |
| 真正需要隐藏 | 接受“Python 做不到强制隐藏”这个事实 |

**能访问 ≠ 该访问。** 封装在 Python 里是一种**契约**，不是一道**墙**。
```

#### 使用
私有成员变量无法被类对象使用，但是可以被其他的成员使用
```
class Student:  
    name = None  
    age = None  
    __tel = '10086'  
  
    def __my_tel(self):  
        print(f'我的号码是{self.__tel}')  
    def use_tel(self):  
        self.__my_tel()  
  
stu_1 = Student()  
stu_1.name = '赵四'  
stu_1.age = 22  
stu_1.use_tel()
```
上面代码当中，`__tel`是私有属性，但是却可以被其他的成员方法`__my_tel`使用
`__my_tel`也是一个私有方法，但是却可以被成员方法`use_tel`调用
`stu_1`虽然不能直接使用`__tel`和`__my_tel`，但是通过`use_tel`最终也间接使用了私有属性和方法
### 继承
**继承**是面向对象编程（OOP）的一个核心概念。简单来说，它允许你定义一个**新类**（子类），这个新类可以**直接拥有另一个已有类（父类）的属性和方法**，而不需要重新编写这些代码
继承分为：单继承和多继承
继承表示：将从父类哪里继承(复制)来成员变量和成员方法(不含私有)
#### 定义
语法：
```
class 类名(父类名):
	类内容体
```

```
class Phone:  
    IMEI = None  
    producer = None  
  
    def call_by_4g(self):  
        print('4g通话')  
  
class Phone2026(Phone):  
    face_id = None  
  
    def call_by_5g(self):  
        print('2026最新5g通话')
```
#### 多继承
Python的类之间也支持多继承
即一个类，可以继承多个父类
语法：
```
class 类名(父类1,父类2,...,父类N):
	类内容体
```

就比如说智能手机嘛
我们肯定知道它是翻盖手机的子类
但其实：
也可以是手电筒的子类
也可以是照相机的子类
等等...
代码实现：
```
class OldPhone:  
    brand = 'Nokia'  
    price = 899.9  
    def call(self):  
        print('滴滴滴，正在呼叫...')  
  
class Camera:  
    brand = 'SONY'  
    price = 1499  
    def shoot(self):  
        print('已打开摄像头')  
  
class Flashlight:  
    brand = 'Fenix'  
    price = 99.9  
    def light(self):  
        print('已打开手电筒')  
  
class NewPhone(OldPhone,Camera,Flashlight):  
    pass  # 当实在需要写点什么，不然语法报错时，就写pass
  
phone1 = NewPhone()  
phone1.call()  
phone1.light()  
phone1.shoot()

# 输出结果
滴滴滴，正在呼叫...
已打开手电筒
已打开摄像头
```
注意事项：
多个父类中，如果有同名的成员，那么默认以继承顺序(从左到右)为优先级
即：先继承的保留，后继承的覆盖
就比如刚刚的代码：
```
print(phone1.brand,phone1.price)
# 那么输出结果将会是：Nokia 899.9
```
#### 复写
##### 介绍
子类继承父类的成员属性和成员方法后，如果对其不满意，那么可以进行复写
即：在子类中重新定义同名的属性和方法
如下：
```
class OldPhone:  
    brand = 'Nokia'  
    price = 899.9  
    def call(self):  
        print('滴滴滴，正在呼叫...')  
  
class Camera:  
    brand = 'SONY'  
    price = 1499  
    def shoot(self):  
        print('已打开摄像头')  
  
class Flashlight:  
    brand = 'Fenix'  
    price = 99.9  
    def light(self):  
        print('已打开手电筒')  
  
class NewPhone(OldPhone,Camera,Flashlight):  
    brand = 'Apple'   
    price = '15999.99'  
    def call(self):  
        print('全新的iPhone Duo正在为您呼叫...')
```
其中这一部分就是对父类的属性和方法进行了重写：
```
	brand = 'Apple'   
    price = '15999.99'  
    def call(self):  
        print('全新的iPhone Duo正在为您呼叫...')
```
##### 调用父类同名成员
一旦复写父类成员，那么类对象调用成员的时候，就会调用复写后的新成员
如果需要使用被复写的父类的成员，需要特殊的调用方式：
方式1：
- 调用父类成员
	- 使用成员变量：父类名.成员变量
	- 使用成员方法：父类名.成员方法(self)
方式2：
- 使用super()调用父类成员
	- 使用成员变量：super().成员变量
	- 使用成员方法：super().成员方法()
如下：
```
class OldPhone:  
    brand = 'Nokia'  
    price = 899.9  
    def call(self):  
        print('滴滴滴，正在呼叫...')  
  
class Camera:  
    brand = 'SONY'  
    price = 1499  
    def shoot(self):  
        print('已打开摄像头')  
  
class Flashlight:  
    brand = 'Fenix'  
    price = 99.9  
    def light(self):  
        print('已打开手电筒')  
  
class NewPhone(OldPhone,Camera,Flashlight):  
    brand = 'Apple'  
    price = '15999.99'  
    def call(self):  
        print('全新的iPhone Duo正在为您呼叫...')  
    def tanks(self):  
        print(f'感谢{super().brand}为我们提供通讯支持')  
        print(f'感谢{Camera.brand}为我们提供相机支持')  
        print(f'感谢{Flashlight.brand}为我们提供手电筒支持')  
phone1 = NewPhone()  
print(phone1.brand,phone1.price)  
phone1.call()  
phone1.tanks()
```
因为多个父类中，如果有同名的成员，那么默认以继承顺序(从左到右)为优先级
所以`super().brand`只能是`OldPhone`的`brand`
```
“在类外面（比如主程序）用 `phone1` 时，你只能拿到 `NewPhone` 自己定义的那个 `Apple` 和 iPhone 呼叫方法。如果你想用父类（旧手机）的 Nokia 或者滴滴滴，你不能直接写在外面，你必须进到 `NewPhone` 类的内部代码里，用 `OldPhone.brand` 或者 `super().brand` 的方式把它特意“抠”出来。”
```
### (插入)类型注解
当我们调用方法，进行传参的时候(快捷键`Ctrl`+`P`弹出提示)：
![[imgs/Pasted image 20260919154130.png]]
![[imgs/Pasted image 20260919154038.png]]
凭什么内置模块`random`的方法可以提示类型
而我们自己定义的就没有呢
- 因为`PyCharm`无法通过代码确定传入什么类型，我们需要使用类型注解
Python在3.5版本的时候引入了类型注解，以方便静态类型检查工具，IDE等第三方工具
#### 介绍
类型注解：
- 在代码中设计数据交互的地方，提供数据类型的注解（显示的说明）。
主要功能：
- 帮助第三方IDE工具（如`PyCharm`）对代码进行类型推断，协助做代码提示
- 帮助开发者自身对变量进行类型注解
支持：
- 变量的类型注解
- 函数（方法）形参列表和返回值的类型注解
#### 语法
##### 为变量设置类型注解
基础语法：`变量:类型`
```
# 基础数据类型注解
var_1: int = 10
var_2: float = 3.1415926
var_3: bool = True
var_4: str = 'yang'
```
```
# 类对象类型注解
class Student:
	pass
stu: student = Student()
```
```
# 基础容器类型注解
my_list: list = [1,2,3]
my_tuple: tuple = (1,2,3)
my_set: set = {1,2,3}
my_dict: dict = {'yang':'handsome'}
my_str: str = '666'

# 容器类型详细注解
my_list: list[int] = [1,2,3]
my_tuple: tuple[str,int,bool] = ('yang',666,True)
my_set: set[int] = {1,2,3}
my_dict: dict[str,int] = {'yang':'666'}
```
注意：
- 元组类型设置类型详细注解，需要将每一个元素都标记出来
- 字典类型设置类型详细注解，需要两个类型，第一个是key第二个是value
##### 通过注释进行类型注解
语法：
```

```
##### 注意
一般只有无法直接看出变量类型时，会添加变量的类型注解，如这种
```

	return 10

```
类型注解的主要功能在于：
- 帮助第三方IDE工具对代码进行类型推断，协助做代码提示
- 帮助开发者自身对变量类型进行类型注释（备注）
并不会真正的对类型做验证和判断。
也就是说，类型注解仅仅是提示性的，不是决定性的
```
var_1: int = 'yang'
var_2: str = 1
```
像这种代码，不会报错哦
**类型注解就只是个备注，不会影响程序的运行**

### 多态
#### 介绍
多态，指的是：多种状态，即完成某个行为时，使用不同的对象会得到不同的状态
同样的行为(函数)，传入不同的对象，得到不同的状态
```
class Animal:  
    def speak(self):  
        pass  
  
class Cat(Animal):  
    def speak(self):  
        print('喵喵喵')  
  
class Dog(Animal):  
    def speak(self):  
        print('汪汪汪')  
  
def make_noisy(animal:Animal):  
    animal.speak()  
  
cat = Cat()  
dog = Dog()  
  
make_noisy(cat)  
make_noisy(dog)
```

多态常作用在继承关系上
比如
- 函数(方法)形参声明接收父类对象
- 实际传入父类的子类对象进行工作
即：
- 以父类做定义声明
- 以子类做实际工作
- 用以获得同一行为，不同状态
就像刚才的代码：
- 以Animal做定义声明
- 实际工作的是子类中重写的方法
- 所以获得了同一行为，却是不同的状态

#### 抽象类(接口)
```
class Animal:  
    def speak(self):  
        pass  
  
class Cat(Animal):  
    def speak(self):  
        print('喵喵喵')  
  
class Dog(Animal):  
    def speak(self):  
        print('汪汪汪')
```
父类Animal的speak方法，是空实现
这种设计的含义是：
- 父类用来确定有哪些方法
- 具体的方法实现，由子类自行决定
这种写法，就叫做抽象类(也可以称之为接口)

抽象类：含有抽象方法的类称之为抽象类
抽象方法：方法体是空实现的(pass)称之为抽象方法

抽象类就好比定义了一个标准
包含了一些抽象的方法，要求子类必须实现
比如说电车和油车：
他们发动机原理完全不同，但是父类Car不需要管你发动机到底是什么原理，反正你必须要有，那就可以写一个方法叫做Engine
子类ElectricCar和GasCar中重写这个方法，里面再讲清楚，电车发动机是怎么将电能转化为动能的，油车发动机是怎么将化学能转化为动能的
Car就是一个抽象类(接口)，Engine就是一个抽象方法

所以抽象类的作用：
- 多用于做顶层设计(设计标准)，以便子类做具体实现
- 也是对子类的一种软性约束，要求子类必须复写(实现)父类的一些方法
- 配合多态去使用，就可以获得不同的工作状态了

# file_define.py

"""  
和文件相关的类定义  
"""  
import json  
from data_define import Record  
  
# 先定义一个抽象类，用来做顶层设计，确定有哪些功能需要实现  
class FileReader:  
    def read_data(self) -> list[Record]:  
        """读取文件的数据，独到的每一条数据都转换为Record对象，将他们封装到list内返回即可"""  
        pass  
  
class TextFileReader(FileReader):  
    def __init__(self,path):  
        self.path = path # 定义成员变量，记录文件的路径  
  
  
    # 复写(实现抽象方法)父类的方法  
    def read_data(self) -> list[Record]:  
        f = open(self.path,'r',encoding='utf-8')  
        record_list: list[Record] = []  
        for line in f.readlines():  
            line = line.strip() # 消除读取到的每一行数据当中的‘\n’  
            data_list = line.split(',')  
            record = Record(data_list[0],data_list[1],int(data_list[2]),data_list[3])  
            record_list.append(record)  
        f.close()  
        return record_list  
  
class JsonFileReader(FileReader):  
    def __init__(self,path):  
        self.path = path  
    def read_data(self) -> list[Record]:  
        f = open(self.path,'r',encoding='utf-8')  
        data_list:list[Record] = []  
        for line in f.readlines():  
            line = json.loads(line)  
            record = Record(line['date'],line['order_id'],int(line['money']),line['province'])  
            data_list.append(record)  
        f.close()  
        return data_list
