# 函数进阶
## 函数的多返回值
如果一个函数要有多个返回值，该如何书写呢？
```
def test_return():  
    return 1,2  
x,y = test_return()  
print(x)  
print(y)

# 运行结果
1
2
```
按照返回值的顺序，写对应多个变量接收即可
变量之间用逗号隔开
支持不同类型的数据return

## 函数的多种传参方式
使用方式上的不同，函数有4种常见参数使用方式
- 位置参数
- 关键字参数
- 缺省参数
- 不定长参数
### 位置参数
调用函数时，根据函数定义的参数位置来传递参数
```
def user_info(name,age,gender):  
    print(f"您的姓名是{name},年龄为{age}岁,性别是{gender}")  
  
user_info('Tom',20,'男')
```
注意：
传递的参数和定义的参数的顺序及个数必须一致

### 关键字参数
函数调用时，通过“键=值”形式传递参数
作用：可以让函数更加清晰、容易使用，同时也清除了参数的顺序要求
```
def user_info(name,age,gender):  
    print(f"您的姓名是{name},年龄为{age}岁,性别是{gender}")  
# 关键字传参，可以不按照固定顺序传参  
user_info(age = 20,name = 'Tom',gender='男')
# 可以和位置参数昏庸，位置参数必须在前，且匹配参数顺序
user_info('Tom',gender='男',age=20)
```
注意：
调用函数时，如果有位置参数，位置参数必须在关键字参数的前面，但关键字参数之间不存在先后顺序

### 缺省参数
缺省参数也叫默认参数，用于定义函数，为参数提供默认值，调用函数时可不传该默认参数的值
（注意：所有位置参数必须出现在默认参数前，包括函数定义和调用）
作用：当调用函数时没有传递参数，就会使用默认用缺省参数对应的值
```
def user_info(name,age,gender='男'):  
    print(f"您的姓名是{name},年龄为{age}岁,性别是{gender}")  
  
  
user_info('Tom',age=20)
user_info('Mary',30,'女')
```
注意：
1. 函数调用时，如果为缺省参数传值则修改默认参数值，否则使用默认值
2. 默认的参数必须写到最后面
```
def user_info(name='Tom',age,gender):  
    print(f"您的姓名是{name},年龄为{age}岁,性别是{gender}")
    
# 就会报错
默认形参后面跟随非默认形参
```
### 不定长参数
不定长参数也叫可变参数，用于不确定调用的时候会传递多少个参数(不传参也可以)的场景
作用：当调用函数时不确定参数个数时，可以使用不定长参数

不定长参数的类型：
- 位置传递
- 关键字传递
#### 位置传递
```
# 单个*号
def user_info(*args):  
    print(args)  
  
  
user_info(123,234)  
user_info('Mary',30,'女')
```
注意：
传进的所有参数都会被args变量收集，它会根据传进参数的位置合并为一个元组(tuple)，args是元组类型，这就是位置传递
#### 关键字传递
```
# 两个*号
def user_info(**kwargs):  
    print(kwargs)  
  
  
user_info(num1 = 123,num2 = 234)  
user_info(name='Mary',age = 30,gender = '女')
```
注意：
参数是“键=值”形式的形式的情况下，所有“键=值”都会被kwargs接收，同时会根据“键=值”组成字典

## 匿名函数
### 函数作为参数传递
在之前的学习中，我们一直使用的函数，都是接收数据作为参数传入：
- 数字
- 字符串
- 字典、列表、元组等
其实，我们学习的函数本身，也可以作为参数传入另一个函数内
如下：
```
def test_func(com):  
    result = com(1,2)  
    print(result)  
  
def compute(x,y):  
    return x+y  
  
test_func(compute)
```
函数compute,作为参数，传入了`test_func`函数中使用
- `test_func`需要一个函数作为参数传入，这个函数需要接收两个数字进行计算，计算逻辑由这个被传入的函数决定
- compute函数接收两个数字对其进行计算，compute函数作为参数，传递给了`test_func`函数使用
- 最终，在`test_func`函数内部，由传入的compute函数，完成了对数字的计算操作
所以，这是一种计算逻辑的传递，而非数据的传递
就像上述代码，不仅仅是相加、相减、相除，等任何逻辑都可以自行定义并作为函数传入
#### lambda匿名函数
函数的定义中
- def关键字，可以定义带有名称的函数
- lambda关键字，可以定义匿名函数(无名称)
有名称的函数，可以基于名称重复使用
无名称的匿名函数，只可临时使用一次

匿名函数定义语法：
`lambda 传入参数: 函数体(一行代码)`
- lambda是关键字，表示定义匿名函数
- 传入参数表示匿名函数的形式参数，如：x,y表示接收2个形式参数
- 函数体，就是函数的执行逻辑，只能写一行，无法写多行

```
def test_func(compute):  
    print(compute(1,2))  
  
test_func(lambda x,y:x+y)
```
通过lambda关键字，传入一个一次性使用的lambda匿名函数
lambda关键字定义的函数是匿名的，无法二次使用


# Python文件操作
## 文件的编码
计算机只能识别：0和1，那么我们丰富的文本文件时如何被计算机识别，并存储在硬盘中呢？

答案是，使用编码技术，将内容翻译成01写入

编码技术即：翻译的规则，记录了如何将内容翻译成二进制，以及如何将二进制翻译回可识别内容

计算机中有许多可用编码
- utf-8
- GBK
- Big5
- 等
不同的编码，将内容翻译成二进制也是不同的

编码有许多种，所以要使用正确的编码，才能对文件进行正确的读写操作

UTF-8是目前全球通用的编码格式
除非有特殊需求，否则，一律以UTF-8格式进行文件编码即可

- 打开文件

#### open()打开文件
在Python中，使用open函数，可以打开一个已经存在的文件，或者创建一个新文件，语法如下：
`open(name,mode,encoding)`
name：是要打开的目标文件名的字符串(可以包含文件所在的具体路径)
mode：设置打开文件的模式(访问模式)：只读、写入、追加等
encoding：编码格式(一般使用UTF-8)
 如：
```
f = open('test.txt','w+',encoding='utf-8')
# encoding的顺序不是第三位，所以不能用位置参数，用关键字参数直接指定
```
注意：
此时`f`是`open`函数的文件对象，对象是Python中一种特殊的数据类型，拥有属性和方法，可以使用`对象.属性`或`对象.方法`对其进行访问

mode常见的三种基础访问模式
- r：以只读方式打开文件。文件的指针将会被放在文件的开头。这是默认模式
- w：打开一个文件只用于写入。如果该文件已存在则打开文件，并从开头开始编辑，原有内容会被删除。如果不存在，创建新文件
- a：打开一个文件用于追加。如果该文件已存在，新的内容将会被写入到已有内容之后。如果该文件不存在，创建新文件进行写入

```
f = open('test.txt','r',encoding='utf-8')  
print(type(f))
# 输出结果
<class '_io.TextIOWrapper'>
# 由此可知：这个对象就是对文本文件进行操作功能的一个对象
```

#### read()方法
read()方法语法：
`文本对象.read(num)`
num表示要从文件中读取的数据的长度(单位是字节)，如果没有什么传入num，那么就表示读取文件中所有的数据
```txt
Yang is the most handsome boy in China,  
more than Peng Yuyan.  
Yang is very brave,intelligent,and outstanding.
```
```
f = open('test.txt',encoding='utf-8')  
print(f"使用read()方法读取20个字节的输出结果是：{f.read(20)}")  
print(f"如果此时再使用read()方法输出结果是：{f.read()}")
f.close()

# 输出结果
使用read()方法读取20个字节的输出结果是：Yang is the most han
如果此时再使用read()方法输出结果是：dsome boy in China,
more than Peng Yuyan.
Yang is very brave,intelligent,and outstanding.
```
第一次read读取到的结尾，就是第二次read的开头
原因：
**每一次读取的时候都会有一个指针，读到哪里，指针就跟着走到哪里**
#### readlines()方法
readlines()方法：
`readlines`可以按照行的方式把整个文件中的内容进行一次性读取，并且返回的是一个**列表**，其中每一行的数据为一个元素
```
f = open('test.txt',encoding='utf-8')  
print( f.readlines())
f.close()

# 输出结果
['Yang is the most handsome boy in China,\n', 'more than Peng Yuyan.\n', 'Yang is very brave,intelligent,and outstanding.']
```
#### readline()方法
readline()方法：一次读取一行数据
```
f = open('test.txt',encoding='utf-8')  
content = f.readline()  
print(f"第一行：{content}")  
content = f.readline()  
print(f"第二行：{content}")  
f.close()

# 输出结果
第一行：Yang is the most handsome boy in China,

第二行：more than Peng Yuyan.
```

## 文件的写入
### 案例演示
```
# 1.打开文件  
f = open('test.txt','w',encoding='utf-8')  
# 2.文件写入  
f.write('Tonight the music seems so loud!')  
# 3.内容刷新  
f.flush()
```
注意：
- 直接调用write，内容并未真正写入文件，而是会积攒再程序的内存中，称之为缓冲区
- 当调用flush的时候，内容才会真正写入文件
- 这样子做是避免频繁的操作硬盘，导致效率下降(攒一堆，一次性写入磁盘)
- close()方法，带有flush()方法的功能

- a模式，文件存在就会再最后，追加写入的文件
