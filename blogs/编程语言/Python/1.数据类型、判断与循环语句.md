## 数据类型
在前面的学习中，我们了解到数据是有类型的
那么，如何验证数据的类型呢？
我们可以通过type()语句来得到数据的类型
语法
```
type(被查看类型的数据)
```
1. 在print语句中，直接输出类型信息
```
print(type("nihao"))

# 运行结果
<class 'str'>
```
2. 用变量存储type()的结果（返回值）
```
type1 = type("nihao")  
type2 = type(123)  
type3 = type(12.123)  
print(type1,type2,type3)

# 运行结果
<class 'str'> <class 'int'> <class 'float'>
```
或者
```
a1 = "nihao"  
a2 = 123  
a3 = 12.123  
  
type1 = type(a1)  
type2 = type(a2)  
type3 = type(a3)  
  
print(type1,type2,type3)

# 运行结果
<class 'str'> <class 'int'> <class 'float'>
```
### 问题
- 我们通过 type(变量) 可以输出类型，这是查看变量的类型还是数据的类型？
查看的是：变量存储的数据的类型。因为**变量无类型**，但是它存储的数据有。
比喻：变量就是个盒子，盒子里面可以装篮球、足球，但是盒子不会变成篮球或者足球

### 字符串格式化
我们会发现，使用＋拼接会出现一些问题
- 变量过多，拼接起来实在是太麻烦了
- 字符串无法和数字或其它类型完成拼接
So，有没有一种既方便又支持拼接其他类型的一种方式呢？
有的兄弟有的
#### 字符串格式化
我们可以通过如下语法，完成字符串和变量的快速拼接
```
lastName = "Romero"  
name = "我的姓是 %s" %lastName  
print(name)

# 输出结果
我的姓是 Romero
```
```
firstName = "Leo"  
lastName = "Romero"  
name = "我的全名是 %s%s" %(firstName,lastName)  
print(name)
# 输出结果
我的全名是 LeoRomero
```
其中的 `%s` 
- % 表示：我要占位
- s 表示：将变量变成字符串放入占位的地方
多个变量占位，变量要用括号括起来，并按照占位的顺序填入
所以，综合起来的意思是：我先占个位置，等一会儿有个变量过来，我把它变成字符串放到占位的位置

#### 常见的占位符
- %s：将内容转换成字符串，放入占位位置
- %d：将内容转换成整数，放入占位位置
- %f：将内容转换成浮点型，放入占位位置
```
year = 2005  
height = 1.70  
name = "yang"  
message = "我是%s,我出生于%d年,我的身高是%fm"%(name,year,height)  
print(message)

# 输出结果
我是yang,我出生于2005年,我的身高是1.700000m
```
### 格式化的精度控制
```
我是yang,我出生于2005年,我的身高是1.700000m
```
这个1.700000m看着很头疼对不对
我们可以使用辅助符号"m.n"来控制数据的宽度和精度
- m，控制宽度，要求是数字（很少使用），设置的宽度小于数字自身，不生效
- .n，控制小数点精度，要求是数字，会进行小数的四舍五入
```
a = 3.1415926  
print("%f"%a)
# 输出：3.141593

a = 3.1415926  
print("%0.7f"%a)
# 输出：3.1415926

a = 3.1415926  
print("%0.9f"%a)
# 输出：3.141592600

a = 3.1415926  
print("圆周率:%10f"%a)
# 输出：圆周率:  3.141593

a = 3.1415926  
print("圆周率:%10.7f"%a)
# 输出：圆周率: 3.1415926
```

## if else 语句

```

	满足条件要做的事情1

else:
	不满足条件要做的事情1

	......

## 判断语句的嵌套
在现实生活中，有很多场景，不仅仅是多个并列条件，还会有满足前置条件才会二次判断的多层判断需求。
对于这种判断需求，可以通过嵌套判断语句来实现
如图：
![[Pasted image 20260906084156.png]]
许多逻辑的判断，是嵌套的，有层次的
对于这种需求，我们可以：自由组合if elif lese,完成特定需求的要求
基础语法如下：
```
if 条件1:
	只满足条件1时做的事情1
	只满足条件1时做的事情2
	......
	
	if 条件2:
	同时满足条件1和2时做的事情1
	同时满足条件1和2时做的事情2
	......


# 'if 条件2'是处于'if 条件1'当中的，只有当条件1满足，才会执行'if 条件2'
```

# Python循环语句
循环普遍存在于我们的日常生活中，同样，在程序中，循环功能也是至关重要的基础功能
## while循环的基础语法
程序中的循环：
```
while 条件:
	条件满足时，做的事情1
	条件满足时，做的事情2
	条件满足时，做的事情3
	......

# 只要条件满足，会无限循环执行
```
比如：
```
# 100个1相加等于多少？

i = 0  
count = 0  
while i < 100:  
    count = count + 1  
    i += 1  
print(count)

# 输出结果
100
```
1. while的条件需要得到布尔类型，True表示继续循环，False表示结束循环
2. 需要设置循环终止的条件，如 i+=1配合i<100，就能确保100次后停止，否则将无限循环
3. 空格缩进和if判断一样，都需要设置

## while循环的嵌套应用

程序中的循环
```
while 条件1:
	条件1满足时，做的事情1
	条件1满足时，做的事情2
	......
	while 条件2:
		条件1、2同时满足时，做的事情1
		条件1、2同时满足时，做的事情2
		......
```
比如：
```
# 每天吃10顿饭,每顿饭吃8个肘子

i = 0  
j = 0  
while i < 10:  
    i += 1  
    print("我要开始吃饭啦，这是我的第%d顿饭"%i)  
    while j < 8:  
        j += 1  
        print("我开始吃了,这是第%d个肘子"%j)  
    j = 0  
    print(f"第{i}顿饭吃完了，好吃好吃！")
```

## for循环的基础语法
### 基础语法
除while循环语句外，Python同样提供了for循环语句。
两者能完成的功能基本差不多，但有一些区别
- while循环的循环条件是自定义的，自行控制循环条件
- for循环时一种“轮询”机制，是对一批内容进行“逐个处理”
程序中的for循环
```
for 临时变量 in 待处理数据集
	循环满足条件时执行的代码
```

```
name = 'yang'
for x in name:
	print(x)
	
# 运行结果
y
a
n
g

# for循环可以将字符串里面的内容一次取出
所以，for循环也被称之为：遍历循环

```
for循环是无法定义循环条件的，只能从被处理的数据集中，依次取出内容进行处理

### range语句

```
for 临时变量 in 待处理数据集
	循环满足条件时执行的代码
```
语法中的：待处理数据集，严格来说，称之为：**序列类型**
序列类型指，其内容可以一个个依次取出的一种类型，包括：
- 字符串
- 列表
- 元组
- 等
for循环语句，本质上是遍历：序列类型
我们可以通过range语句，获得一个简单的数字序列

1. 语法1
```
range(num)
```
获取一个从0开始，到num结束的数字序列(不包含num本身)

2. 语法2
```
range(num1,num2)
```
获得一个从num1开始，到num2结束的数字序列(不包含num2本身)
```
range(5,10)
# 获取的就是：[5,6,7,8,9]
```
3. 语法3
```
range(num1,num2,step)
```
获得一个从num1开始，到num2结束的数字序列(不包含num2本身)
数字之间的步长，以step为准(step默认为1)
```
range(5,10,2)
# 获取的就是：[5,7,9]
```

## 循环中断
无论是while循环还是for循环，都是重复性的执行特定操作。
在这个重复的过程中，会出现一些其他情况让我们不得不：
- 暂时跳过某次循环，直接进行下一次
- 提前退出循环，不再继续

对于这种场景，Python提供了continue和break关键字
用以对循环进行临时跳过和直接结束

### continue
continue关键字用于：中断本次循环，直接进入下一次循环
continue可以用于：for循环和while循环，效果一致
```
for i in range(1,100):
	语句1
	continue
	语句2
```
- 在循环内，遇到continue就结束当次循环，进行下一次
- 所以，语句2永远不会执行

continue关键字只可以控制，它所在的循环临时中断 
```
for i in range(1,100):
	语句1
	for i in range(1,100):
		语句2
		continue
		语句3
	语句4
```
如上，（语句1执行1次，语句2执行99次，语句4执行1次）按这个顺序执行99次，语句3永远不会执行
### break
break关键字用于：直接结束循环
break可以用于：for循环和while循环，效果一致
```
for i in range(1,100):
	语句1
	break
	语句2
语句3
```
在第一次执行的时候，语句1执行完，就跳出循环了，执行一次语句3，结束

```
import random  
balance = 10000  
  
for i in range(1,21):  
    num = random.randint(1,10)  
    if num < 5:  
        print(f"{i}号员工，绩效分{num},吃饱饭不干活，不发工资")  
        continue  
    balance = balance-1000  
    print(f"向{i}号员工发放工资1000元！账户余额{balance}元")  
    if balance == 0:  
        print("公司没钱了，咱们好聚好散吧")  
        break
