## 激活虚拟环境
我们需要一个独立的虚拟环境来进行安全的开发
所以
```
# 创建虚拟环境
PS E:\CodeProfiles\python\project11> python -m venv .venv
# 激活虚拟环境
PS E:\CodeProfiles\python\project11> .\.venv\Scripts\Activate.ps1
.\.venv\Scripts\Activate.ps1 : 无法加载文件 E:\CodeProfiles\python\project11\.venv\Scripts\Activate.ps1，因为在此
系统上禁止运行脚本。有关详细信息，请参阅 https:/go.microsoft.com/fwlink/?LinkID=135170 中的 about_Execution_Polici
es。
所在位置 行:1 字符: 1
+ .\.venv\Scripts\Activate.ps1
+ ~~~~~~~~~~~~~~~~~~~~~~~~~~~~
    + CategoryInfo          : SecurityError: (:) []，PSSecurityException
    + FullyQualifiedErrorId : UnauthorizedAccess
# 哎呀，报错了，我们直接以管理员身份运行
PS E:\CodeProfiles\python\project11> Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
# 再次激活
PS E:\CodeProfiles\python\project11> .\.venv\Scripts\Activate.ps1
# 进入虚拟环境了
(.venv) PS E:\CodeProfiles\python\project11> 
```
## 临时使用清华源
在VS Code终端中执行以下命令（确保虚拟环境已经激活）：
`pip install langchain langgraph langchain-openai -i https://pypi.tuna.tsinghua.edu.cn/simple`

或者
如果你想让所有pip安装默认使用清华源：
`pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple`

### 从requirements.txt安装依赖
可以将用到的包写入requirements.txt
```
(.venv) PS E:\CodeProfiles\python\project11> pip freeze > requirements.txt
```
```
# 一条命令安装里面的包
pip install -r requiremnts.txt
```
