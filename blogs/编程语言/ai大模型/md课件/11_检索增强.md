# 11 检索增强

## 学习目标
1. 理解 RAG（Retrieval-Augmented Generation，检索增强生成）的核心原理
2. 掌握文档加载、文本分割、向量化的基本流程
3. 学会使用 LangChain 构建简单的 RAG 问答链
4. 理解检索器（Retriever）在智能体中的作用
5. 能够处理本地文本数据并基于其回答问题

## 1. 为什么需要 RAG

大语言模型有两个明显局限：

- **知识过时**：模型训练数据有截止日期，不知道最新信息
- **容易产生幻觉**：对未训练过的问题可能编造答案

**RAG** 通过在回答前先从外部知识库中检索相关信息，把检索到的内容作为上下文喂给模型，从而：

- 让模型基于最新、准确的资料回答
- 减少幻觉
- 实现私有知识库问答（如公司文档、个人笔记）

## 2. RAG 的核心流程

一个完整的 RAG 系统通常包含以下步骤：

```
1. 加载文档     -> DocumentLoader
2. 分割文档     -> TextSplitter
3. 文本向量化   -> Embeddings
4. 存入向量库   -> VectorStore
5. 用户提问     -> Query
6. 检索相关片段 -> Retriever
7. 拼接上下文   -> Context
8. 生成回答     -> LLM
```

其中第 1-4 步是「离线」的索引阶段，第 5-8 步是「在线」的查询阶段。

### 5.1 使用 LangChain 的 TextLoader（推荐）

`TextLoader` 可以自动处理编码、元数据等问题。

> 注意：`langchain-community` 在 LangChain 1.x 中已被标记为弃用，但仍然可用。代码中用 `warnings.filterwarnings('ignore', category=DeprecationWarning)` 过滤了警告。

```python
import warnings

# langchain-community 在 LangChain 1.x 中已被标记为弃用，但仍然可用
# 这里过滤掉 DeprecationWarning，避免输出中显示警告信息
warnings.filterwarnings('ignore', category=DeprecationWarning)

from langchain_community.document_loaders import TextLoader

loader = TextLoader('sample_rag.txt', encoding='utf-8')
documents = loader.load()

print(f'加载了 {len(documents)} 个文档')
print(f'第一个文档长度：{len(documents[0].page_content)} 字符')
print(f'元数据：{documents[0].metadata}')
```

### 5.2 原生 Python 加载方式（备用）

## 6. 文档分割

大模型一次能处理的文本长度有限，而且过长的文档会影响检索精度。因此需要把长文档切分成小块。

```python
from langchain_text_splitters import RecursiveCharacterTextSplitter

# 创建一个文本分割器
# chunk_size: 每个块的最大字符数
# chunk_overlap: 相邻块之间的重叠字符数，用于保持上下文连贯
splitter = RecursiveCharacterTextSplitter(
    chunk_size=100,
    chunk_overlap=20,
    separators=['\n\n', '\n', '。', '，', ' ', '']
)

chunks = splitter.split_documents(documents)

print(f'分割成 {len(chunks)} 个文本块')
for i, chunk in enumerate(chunks[:3]):
    print(f'\n--- 第 {i+1} 块 ---')
    print(chunk.page_content[:80] + '...')
```

### 代码解释

- `chunk_size`：每个文本块的最大长度
- `chunk_overlap`：相邻块重叠的字符数，避免关键信息被切分断掉
- `separators`：切分优先级，先按段落切，再按句子切，最后按字符切
- `RecursiveCharacterTextSplitter` 会尽量在语义边界处切分

## 7. 文本向量化

向量化是把文本转换成数值向量的过程。语义相近的文本，向量距离也更近。

本课件使用 `OpenAIEmbeddings`。如果你的 API 不支持 `qwen3-embedding`，请把 `model` 参数改成你实际可用的 embedding 模型名。

```python
from langchain_openai import OpenAIEmbeddings
from dotenv import load_dotenv

load_dotenv()


# 创建 embedding 模型
# 如果你的 API 提供的是其他 embedding 模型名，请修改 model 参数
embeddings = OpenAIEmbeddings(model='qwen3-embedding')

# 测试向量化
test_text = '人工智能是计算机科学的分支'
vector = embeddings.embed_query(test_text)

print(f'文本：{test_text}')
print(f'向量维度：{len(vector)}')
print(f'向量前5个值：{vector[:5]}')
```

### 备用方案：使用 FakeEmbeddings 测试流程

如果你暂时没有可用的 embedding 接口，可以用 `FakeEmbeddings` 仅测试 RAG 流程。注意：FakeEmbeddings 生成的向量是随机的，检索结果没有实际语义意义。

```python
from langchain_core.embeddings import FakeEmbeddings

# 仅用于测试流程，向量维度设为 384
fake_embeddings = FakeEmbeddings(size=384)

fake_vector = fake_embeddings.embed_query('测试文本')
print(f'Fake 向量维度：{len(fake_vector)}')
```

## 8. 向量存储与检索

把分割后的文本块存入向量数据库。这里使用 `InMemoryVectorStore`，它是一个内存型向量存储，适合学习和测试。

```python
from langchain_core.vectorstores import InMemoryVectorStore

# 创建内存向量库
vectorstore = InMemoryVectorStore(embeddings)

# 把文本块加入向量库
vectorstore.add_documents(chunks)

# 创建检索器，k=2 表示返回最相关的 2 个片段
retriever = vectorstore.as_retriever(search_kwargs={'k': 2})

# 测试检索
query = '什么是深度学习？'
retrieved_docs = retriever.invoke(query)

print(f'检索到 {len(retrieved_docs)} 个相关片段：\n')
for i, doc in enumerate(retrieved_docs):
    print(f'--- 片段 {i+1} ---')
    print(doc.page_content)
    print(f'来源：{doc.metadata}\n')
```

### 代码解释

- `InMemoryVectorStore(embeddings)`：创建内存向量库，使用指定的 embedding 模型
- `add_documents(chunks)`：把文本块存入向量库
- `as_retriever(search_kwargs={'k': 2})`：把向量库转成检索器，每次返回前 2 个最相关结果
- `retriever.invoke(query)`：根据用户问题检索相关文本块

## 9. 构建 RAG 问答链

把检索器和 LLM 组合起来，构建一个完整的 RAG 链。流程是：

1. 接收用户问题
2. 用检索器找到相关文档
3. 把文档内容拼接到 Prompt 中
4. 让 LLM 基于上下文回答

```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough

llm = ChatOpenAI(model='qwen3.6-35b-A3b', temperature=0.1)

# 定义 RAG Prompt 模板
rag_prompt = ChatPromptTemplate.from_messages([
    ('system', '你是一个知识库问答助手。请根据下面的上下文回答问题，如果上下文没有相关信息，请说「我不知道」。'),
    ('user', '''上下文：\n{context}\n\n问题：{question}''')
])

# 把检索到的文档拼接成字符串
def format_docs(docs):
    return '\n\n'.join([doc.page_content for doc in docs])

# 构建 RAG 链
rag_chain = (
    {'context': retriever | format_docs, 'question': RunnablePassthrough()}
    | rag_prompt
    | llm
    | StrOutputParser()
)

# 测试
question = '深度学习和大语言模型有什么关系？'
answer = rag_chain.invoke(question)
print('问题：', question)
print('\n回答：', answer)
```

### 代码解释

- `{'context': retriever | format_docs, 'question': RunnablePassthrough()}`：
  - `context` 分支：用检索器找到相关文档，再用 `format_docs` 拼接成字符串
  - `question` 分支：用 `RunnablePassthrough()` 把原始问题传递下去
- `rag_prompt`：把 context 和 question 填充到模板中
- `llm`：让模型基于上下文生成回答
- `StrOutputParser()`：把 AIMessage 转成字符串

## 10. 完整示例：基于私有文档的问答系统

下面把前面的步骤整合成一个完整的 RAG 系统。

```python
from langchain_community.document_loaders import TextLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_core.vectorstores import InMemoryVectorStore
from langchain_openai import ChatOpenAI, OpenAIEmbeddings
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough

# 1. 加载文档
loader = TextLoader('sample_rag.txt', encoding='utf-8')
documents = loader.load()

# 2. 分割文档
splitter = RecursiveCharacterTextSplitter(chunk_size=100, chunk_overlap=20)
chunks = splitter.split_documents(documents)

# 3. 创建 embedding 和向量库
embeddings = OpenAIEmbeddings(model='qwen3-embedding')
vectorstore = InMemoryVectorStore(embeddings)
vectorstore.add_documents(chunks)

# 4. 创建检索器
retriever = vectorstore.as_retriever(search_kwargs={'k': 2})

# 5. 创建 LLM 和 Prompt
llm = ChatOpenAI(model='qwen3.6-35b-A3b', temperature=0.1)
prompt = ChatPromptTemplate.from_messages([
    ('system', '你是知识库问答助手，请严格根据上下文回答。'),
    ('user', '''上下文：\n{context}\n\n问题：{question}''')
])

def format_docs(docs):
    return '\n\n'.join([doc.page_content for doc in docs])

# 6. 构建 RAG 链
qa_chain = (
    {'context': retriever | format_docs, 'question': RunnablePassthrough()}
    | prompt
    | llm
    | StrOutputParser()
)

# 7. 提问
questions = [
    '机器学习是什么？',
    '自然语言处理和大语言模型有什么关系？',
    '苹果是什么颜色的？'  # 这个问题不在文档中，观察模型是否说不知道
]

for q in questions:
    print(f'Q: {q}')
    print(f'A: {qa_chain.invoke(q)}\n')
```

## 11. RAG 系统的优化方向

实际应用中，RAG 系统还有很多优化空间：

| 优化方向 | 说明 |
| --- | --- |
| **更好的分块策略** | 按语义、按段落、按标题切分，避免切断关键信息 |
| **更优的 Embedding 模型** | 使用针对中文优化的模型，如 BGE、M3E 等 |
| **重排序（Rerank）** | 先检索多个候选，再用更精确的模型排序 |
| **查询改写** | 把用户问题改写成更适合检索的形式 |
| **持久化向量库** | 使用 Chroma、FAISS、Milvus 等持久化存储 |
| **元数据过滤** | 根据来源、时间、类别等元数据进行筛选 |
