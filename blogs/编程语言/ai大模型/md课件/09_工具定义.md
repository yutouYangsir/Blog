# 09 工具定义

## 学习目标
1. 理解工具（Tools）在智能体开发中的核心作用
2. 掌握使用 `@tool` 装饰器定义自定义工具
3. 学会为工具编写清晰的参数说明和文档字符串
4. 理解工具描述如何影响模型选择工具的能力
5. 能够定义计算类、查询类和文件处理类工具

## 1. 为什么需要工具

大语言模型本身只能处理文本，它的知识截止于训练数据，也无法直接访问外部世界。

**工具（Tools）** 让模型能够：

- 执行数学计算（模型不擅长精确计算）
- 查询数据库、API、搜索引擎
- 读写文件、操作数据库
- 获取实时信息（天气、股价、新闻）

智能体（Agent）的核心工作就是：**根据用户问题选择合适的工具，调用工具，再根据结果回答问题**。

## 2. 使用 @tool 装饰器定义第一个工具

LangChain 提供了 `@tool` 装饰器，可以把一个普通 Python 函数变成智能体可调用的工具。

```python
from langchain.tools import tool

# 使用 @tool 装饰器定义一个加法工具
@tool
def add(a: int, b: int) -> int:
    """计算两个整数的和。"""
    return a + b

# 查看工具信息
print('工具名称：', add.name)
print('工具描述：', add.description)
print('参数Schema：', add.args)
```

### 代码解释

- `@tool`：把 `add` 函数注册为 LangChain 工具
- `a: int, b: int`：参数类型会被自动解析为工具的输入参数格式
- 函数文档字符串 `"""..."""`：会被自动提取为工具描述（description）
- `add.name`：工具名，默认使用函数名
- `add.description`：工具描述，来自函数的 docstring
- `add.args`：参数的 JSON Schema，模型根据它决定如何传参

## 3. 手动调用工具

工具定义好后，可以通过 `invoke` 方法或 `run` 方法调用。

注意：`@tool` 装饰后的对象是一个 `StructuredTool` 对象，**不能直接像普通函数那样加括号调用**（如 `multiply(3, 4)`），需要传入字典参数。

```python
from langchain.tools import tool

@tool
def multiply(a: int, b: int) -> int:
    """计算两个整数的乘积。"""
    return a * b

# 通过 invoke 调用，传入字典参数
print('invoke 调用：', multiply.invoke({'a': 3, 'b': 4}))

# 通过 run 调用（LangChain 工具的传统调用方式）
print('run 调用：', multiply.run({'a': 5, 'b': 6}))
```

### 代码解释

- `@tool` 装饰后的对象是一个 `StructuredTool`，不是普通函数
- `multiply.invoke({'a': 3, 'b': 4})`：LangChain 风格调用，智能体实际使用这种方式
- `multiply.run({'a': 5, 'b': 6})`：传统工具调用方式，与 `invoke` 效果相同
- 注意：不能写成 `multiply(3, 4)`，否则会报 `StructuredTool object is not callable`

## 4. 自定义工具名称和描述

默认情况下，工具名就是函数名，描述来自 docstring。你也可以通过 `@tool` 参数自定义。

```python
from langchain.tools import tool

@tool('weather-query', description='查询指定城市的当前天气情况')
def get_weather(city: str) -> str:
    """
    查询天气。
    参数：
        city: 城市名称，例如 "北京"、"上海"
    """
    # 这里用模拟数据，实际可接入天气 API
    weather_data = {
        '北京': '晴，25°C',
        '上海': '多云，28°C',
        '广州': '小雨，30°C'
    }
    return weather_data.get(city, f'未找到 {city} 的天气信息')

print('工具名称：', get_weather.name)
print('工具描述：', get_weather.description)
print('调用结果：', get_weather.invoke({'city': '北京'}))
```

### 代码解释

- `@tool('weather-query', description='...')`：自定义工具名和描述
- 工具描述非常重要，模型主要依赖它判断什么时候使用该工具
- 描述要清晰、具体，包含「工具能做什么」和「参数含义」
- 函数 docstring 可以继续补充参数细节

## 5. 定义带多个参数的工具

工具可以有多个参数，LangChain 会自动根据类型注解生成参数 Schema。

```python
from langchain.tools import tool

@tool
def calculate_bmi(height: float, weight: float) -> str:
    """
    根据身高和体重计算 BMI 指数，并返回健康建议。
    参数：
        height: 身高，单位米
        weight: 体重，单位千克
    """
    bmi = weight / (height ** 2)
    if bmi < 18.5:
        suggestion = '体重过轻，建议加强营养'
    elif bmi < 24:
        suggestion = '体重正常，请保持'
    elif bmi < 28:
        suggestion = '超重，建议适当运动'
    else:
        suggestion = '肥胖，建议咨询医生'
    return f'BMI: {bmi:.2f}，{suggestion}'

print(calculate_bmi.invoke({'height': 1.75, 'weight': 70}))
print('\n参数 Schema：')
print(calculate_bmi.args)
```

### 代码解释

- `height: float, weight: float`：类型注解会被 LangChain 自动识别
- 生成的 `args` 中会包含参数名、类型、是否必填等信息
- 模型会根据这个 Schema 构造正确的 JSON 参数调用工具

## 6. 定义模拟 API 查询工具

实际应用中，工具通常会调用外部 API。下面我们用一个模拟的「产品库存查询」工具来演示。

```python
from langchain.tools import tool

@tool
def query_product_stock(product_name: str) -> str:
    """
    查询指定商品的库存数量。
    参数：
        product_name: 商品名称
    """
    # 模拟数据库查询
    stock_db = {
        '手机': 150,
        '笔记本电脑': 45,
        '耳机': 200,
        '充电宝': 80
    }
    stock = stock_db.get(product_name)
    if stock is None:
        return f'未找到商品 "{product_name}" 的库存信息'
    return f'商品 "{product_name}" 当前库存：{stock} 件'

# 测试工具
print(query_product_stock.invoke({'product_name': '手机'}))
print(query_product_stock.invoke({'product_name': '相机'}))
```

### 代码解释

- 这个工具模拟了查询数据库或 API 的场景
- 返回的字符串会作为观察结果（Observation）交给模型继续处理
- 工具内部可以替换为真实的数据库查询、HTTP 请求等

## 7. 定义文件处理工具

工具也可以读写文件。下面是读取文本文件和写入文本文件的工具示例。

```python
from langchain.tools import tool

@tool
def read_text_file(file_path: str) -> str:
    """
    读取指定文本文件的内容。
    参数：
        file_path: 文件路径
    """
    try:
        with open(file_path, 'r', encoding='utf-8') as f:
            return f.read()
    except FileNotFoundError:
        return f'文件不存在：{file_path}'
    except Exception as e:
        return f'读取失败：{str(e)}'

@tool
def write_text_file(file_path: str, content: str) -> str:
    """
    将内容写入指定文本文件。
    参数：
        file_path: 文件路径
        content: 要写入的内容
    """
    try:
        with open(file_path, 'w', encoding='utf-8') as f:
            f.write(content)
        return f'已成功写入文件：{file_path}'
    except Exception as e:
        return f'写入失败：{str(e)}'

# 测试写入和读取
write_text_file.invoke({'file_path': 'test_note.txt', 'content': '这是测试内容'})
print(read_text_file.invoke({'file_path': 'test_note.txt'}))
```

### 代码解释

- `read_text_file`：读取指定文件内容
- `write_text_file`：把字符串写入指定文件
- 文件路径使用相对路径时，会以当前工作目录为基准
- 工具内部要做好异常处理，避免程序崩溃

## 8. 工具列表与工具选择

在构建智能体时，通常会把多个工具放在一个列表里，交给模型选择使用。

```python
from langchain.tools import tool

@tool
def add(a: int, b: int) -> int:
    """计算两个整数的和。"""
    return a + b

@tool
def multiply(a: int, b: int) -> int:
    """计算两个整数的乘积。"""
    return a * b

@tool
def power(base: int, exponent: int) -> int:
    """计算 base 的 exponent 次方。"""
    return base ** exponent

# 把工具放入列表
tools = [add, multiply, power]

# 查看工具列表信息
for t in tools:
    print(f'名称：{t.name}，描述：{t.description}')
```

### 代码解释

- 智能体通过工具列表了解有哪些工具可用
- 模型会根据用户问题和工具描述，决定调用哪个工具、传什么参数
- 工具名称和描述的清晰度直接影响模型选择工具的准确率

## 9. 完整示例：多功能计算器工具集

下面把多个数学工具组合成一个工具集，模拟智能体可使用的工具环境。

```python
from langchain.tools import tool

@tool
def add(a: float, b: float) -> float:
    """计算两个数的和。"""
    return a + b

@tool
def subtract(a: float, b: float) -> float:
    """计算两个数的差。"""
    return a - b

@tool
def multiply(a: float, b: float) -> float:
    """计算两个数的乘积。"""
    return a * b

@tool
def divide(a: float, b: float) -> float:
    """计算两个数的商，如果除数为0则返回错误信息。"""
    if b == 0:
        return '错误：除数不能为0'
    return a / b

math_tools = [add, subtract, multiply, divide]

# 测试每个工具
for t in math_tools:
    print(f'{t.name}: {t.description}')
```
