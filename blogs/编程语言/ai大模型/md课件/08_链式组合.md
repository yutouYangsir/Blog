# 08 链式组合

## 学习目标
1. 深入理解 LCEL（LangChain Expression Language）管道符 `|` 的组合原理
2. 掌握 `Runnable` 接口的核心方法：`invoke`、`batch`、`stream`、`ainvoke`
3. 学会在链中使用 `RunnableLambda` 进行数据格式转换
4. 理解 `RunnableParallel` 并行执行多个子链
5. 能够构建复杂的多步骤处理链

## 1. 什么是 LCEL 链式组合

LCEL 是 LangChain 推荐的新一代链式组合语法。它用管道符 `|` 把各个组件串联起来，就像 Linux 命令行一样直观。

```
chain = component_a | component_b | component_c
```

数据流：
```
输入 -> component_a -> 中间结果 -> component_b -> 中间结果 -> component_c -> 输出
```

LCEL 中的每个组件都实现了 `Runnable` 接口，它们都有统一的方法签名。

## 2. Runnable 接口的核心方法

所有 LCEL 组件都实现了以下方法：

| 方法 | 作用 |
| --- | --- |
| `invoke(input)` | 单条同步调用 |
| `batch(inputs)` | 批量同步调用 |
| `stream(input)` | 流式输出 |
| `ainvoke(input)` | 异步单条调用 |
| `abatch(inputs)` | 异步批量调用 |

这些方法不仅单个组件有，组合后的链也有。

```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from dotenv import load_dotenv

load_dotenv()


llm = ChatOpenAI(model='qwen3.6-35b-A3b', temperature=0.7)

# 构建一个简单链
prompt = ChatPromptTemplate.from_messages([
    ('system', '你是一个翻译助手。'),
    ('user', '把以下中文翻译成英文：{text}')
])

chain = prompt | llm | StrOutputParser()

# 使用 invoke 单条调用
result = chain.invoke({'text': '人工智能'})
print('invoke 结果：', result)

# 使用 batch 批量调用
results = chain.batch([
    {'text': '苹果'},
    {'text': '香蕉'},
    {'text': '机器学习'}
])
print('\nbatch 结果：', results)

# 使用 stream 流式输出
print('\nstream 结果：')
for chunk in chain.stream({'text': '未来科技'}):
    print(chunk, end='')
print()
```

### 代码解释

- `prompt` 接收字典，输出格式化后的消息列表
- `llm` 接收消息列表，输出 `AIMessage`
- `StrOutputParser()` 接收 `AIMessage`，输出字符串
- 组合后的 `chain` 继承了三个组件的能力，可以直接调用 `invoke`、`batch`、`stream`

## 3. 使用 RunnableLambda 转换数据

在组合链时，前一个组件的输出格式可能和后一个组件的输入格式不匹配。

例如：前一个链输出字符串，后一个链需要字典。这时可以用 `RunnableLambda` 或普通 lambda 函数做转换。

```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnableLambda

llm = ChatOpenAI(model='qwen3.6-35b-A3b', temperature=0.7)

# 第一步：把中文翻译成英文
translate_prompt = ChatPromptTemplate.from_messages([
    ('system', '你是一个翻译助手。'),
    ('user', '把以下中文翻译成英文：{text}')
])
translate_chain = translate_prompt | llm | StrOutputParser()

# 第二步：把英文总结成一句话
summarize_prompt = ChatPromptTemplate.from_messages([
    ('system', '你是一个总结助手。'),
    ('user', '请用一句话总结以下内容：{text}')
])
summarize_chain = summarize_prompt | llm | StrOutputParser()

# 翻译链输出字符串，但总结链需要字典 {text: ...}
# 使用 RunnableLambda 做格式转换
def to_dict(text):
    return {'text': text}

# 组合链：翻译 -> 转字典 -> 总结
full_chain = translate_chain | RunnableLambda(to_dict) | summarize_chain

result = full_chain.invoke({'text': '大语言模型开发效率比较高，而且比较聪明，而且成本比较低，大家都在学习怎么使用，正在改变软件的开发方式。'})
print('最终结果：', result)
```

### 代码解释

| 组件 | 输入 | 输出 |
| --- | --- | --- |
| `translate_chain` | `{'text': '...'}` | 英文字符串 |
| `RunnableLambda(to_dict)` | 英文字符串 | `{'text': '...'}` |
| `summarize_chain` | `{'text': '...'}` | 总结字符串 |

`RunnableLambda` 把一个普通函数包装成 Runnable，可以无缝接入链中。

## 4. 直接传递多个变量：RunnableParallel

`RunnableParallel` 允许你同时运行多个子链，并把多个结果合并成一个字典。

它适合的场景：
- 同时让模型做翻译和总结
- 同时提取不同类型的信息
- 一个输入需要生成多个输出

```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnableParallel

llm = ChatOpenAI(model='qwen3.6-35b-A3b', temperature=0.7)

# 定义多个子链
translate_prompt = ChatPromptTemplate.from_messages([
    ('system', '你是翻译助手。'),
    ('user', '把以下中文翻译成英文：{text}')
])
translate_chain = translate_prompt | llm | StrOutputParser()

summary_prompt = ChatPromptTemplate.from_messages([
    ('system', '你是总结助手。'),
    ('user', '用一句话总结：{text}')
])
summary_chain = summary_prompt | llm | StrOutputParser()

keywords_prompt = ChatPromptTemplate.from_messages([
    ('system', '你是关键词提取助手。'),
    ('user', '提取3个关键词，用逗号分隔：{text}')
])
keywords_chain = keywords_prompt | llm | StrOutputParser()

# 并行执行三个子链，输入都是 {'text': '...'}
parallel_chain = RunnableParallel(
    translation=translate_chain,
    summary=summary_chain,
    keywords=keywords_chain
)

result = parallel_chain.invoke({'text': '人工智能正在改变教育、医疗和交通行业'})

print('返回类型：', type(result))
print('翻译结果：', result['translation'])
print('总结结果：', result['summary'])
print('关键词结果：', result['keywords'])
```

### 代码解释

- `RunnableParallel(...)` 接收一个字典，键是输出字段名，值是子链
- 所有子链会同时接收同一个输入 `{'text': '...'}`
- 返回结果是一个字典，包含每个子链的输出
- 适合需要「一次输入、多种处理」的场景

## 5. 组合并行与串行

`RunnableParallel` 的输出是一个字典，可以继续传给下一个组件使用。

例如：先并行做翻译和总结，再把结果合并成一个报告。

```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnableParallel

llm = ChatOpenAI(model='qwen3.6-35b-A3b', temperature=0.7)

# 并行生成翻译和总结
parallel_chain = RunnableParallel(
    translation=(
        ChatPromptTemplate.from_messages([
            ('system', '翻译助手'),
            ('user', '把中文翻译成英文：{text}')
        ]) | llm | StrOutputParser()
    ),
    summary=(
        ChatPromptTemplate.from_messages([
            ('system', '总结助手'),
            ('user', '用一句话总结：{text}')
        ]) | llm | StrOutputParser()
    )
)

# 把并行结果合并成最终报告
report_prompt = ChatPromptTemplate.from_messages([
    ('system', '你是一个报告生成助手。'),
    ('user', '''请根据以下翻译和总结生成一份简短报告：\n\n翻译：{translation}\n总结：{summary}\n\n请输出包含「原文概要」和「英文翻译」两部分的报告。''')
])

full_chain = parallel_chain | report_prompt | llm | StrOutputParser()

result = full_chain.invoke({'text': '大语言模型开发效率比较高，而且比较聪明，而且成本比较低，大家都在学习怎么使用，正在改变软件的开发方式。'})
print(result)
```

### 代码解释

| 阶段 | 说明 |
| --- | --- |
| `parallel_chain` | 同时生成翻译和总结，输出 `{'translation': ..., 'summary': ...}` |
| `report_prompt` | 接收字典，用 `{translation}` 和 `{summary}` 填充模板 |
| `llm \| StrOutputParser()` | 生成最终报告 |

这种「先并行、再串行」的模式在实际应用中非常常见。

## 6. 条件分支：RunnableBranch

`RunnableBranch` 可以根据条件选择不同的子链执行。

例如：根据输入语言类型选择不同的处理链。

```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnableBranch, RunnableLambda

llm = ChatOpenAI(model='qwen3.6-35b-A3b', temperature=0.1)

# 定义两个处理链
chinese_chain = (
    ChatPromptTemplate.from_messages([
        ('system', '你是中文助手。'),
        ('user', '请用中文解释：{text}')
    ]) | llm | StrOutputParser()
)

english_chain = (
    ChatPromptTemplate.from_messages([
        ('system', 'You are an English assistant.'),
        ('user', 'Please explain in English: {text}')
    ]) | llm | StrOutputParser()
)

# 判断输入文本是否包含中文字符
def is_chinese(input_dict):
    text = input_dict['text']
    return any('\u4e00' <= char <= '\u9fff' for char in text)

# 构建分支链
branch_chain = RunnableBranch(
    (is_chinese, chinese_chain),
    english_chain  # 默认分支
)

print('中文输入结果：')
print(branch_chain.invoke({'text': '神经网络'})[:250])

print('\n英文输入结果：')
print(branch_chain.invoke({'text': 'neural network'})[:250])
```

### 代码解释

- `RunnableBranch` 接收多个 `(条件函数, 子链)` 元组，最后是默认子链
- 条件函数接收链的输入，返回 `True` 或 `False`
- 从上往下匹配，第一个条件为 `True` 的分支会被执行
- 如果没有匹配，执行默认分支

注意：条件函数处理的输入是整个链的输入（这里是字典），不是前一个组件的输出。

## 7. 查看链的结构

复杂的链可以通过 `get_graph().print_ascii()` 方法查看结构。它会用 ASCII 字符打印出链中的节点和连接关系，非常直观。

> 需要安装依赖：`pip install grandalf`
> 安装后请**重启 Jupyter 内核**再运行本单元格。

```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

llm = ChatOpenAI(model='qwen3.6-35b-A3b', temperature=0.7)

chain = (
    ChatPromptTemplate.from_messages([
        ('user', '把以下内容翻译成英文：{text}')
    ])
    | llm
    | StrOutputParser()
    | (lambda x: {'text': x})
    | ChatPromptTemplate.from_messages([
        ('user', '用一句话总结：{text}')
    ])
    | llm
    | StrOutputParser()
)

# 打印链的 ASCII 结构图
chain.get_graph().print_ascii()
```

### 代码解释

- `get_graph()` 获取链的图结构对象
- `print_ascii()` 用 ASCII 字符画出节点和边
- 可以清楚地看到数据从输入到输出经过了哪些步骤
- 如果提示缺少 `grandalf`，请先安装：`pip install grandalf`，然后重启 Jupyter 内核

## 8. 完整示例：智能客服工单处理

下面是一个综合示例：用户输入一条投诉或咨询，系统同时完成情绪分析、分类、生成回复建议。

```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnableParallel

llm = ChatOpenAI(model='qwen3.6-35b-A3b', temperature=0.3)

# 并行分析：情绪 + 分类 + 摘要
# 注意：reply_prompt 中还需要原始输入 text，所以这里用 lambda 把 text 一起传下去
analysis_chain = RunnableParallel(
    text=lambda x: x['text'],
    sentiment=(
        ChatPromptTemplate.from_messages([
            ('system', '情绪分析助手，只输出：正面/负面/中性'),
            ('user', '{text}')
        ]) | llm | StrOutputParser()
    ),
    category=(
        ChatPromptTemplate.from_messages([
            ('system', '分类助手，只输出类别：售后/产品/物流/其他'),
            ('user', '{text}')
        ]) | llm | StrOutputParser()
    ),
    summary=(
        ChatPromptTemplate.from_messages([
            ('system', '摘要助手，用一句话概括'),
            ('user', '{text}')
        ]) | llm | StrOutputParser()
    )
)

# 根据分析结果生成回复建议
reply_prompt = ChatPromptTemplate.from_messages([
    ('system', '你是客服主管，请根据分析结果生成回复建议。'),
    ('user', '''用户反馈：{text}

分析结果：
- 情绪：{sentiment}
- 类别：{category}
- 摘要：{summary}

请生成一段礼貌、专业的回复建议。''')
])

full_chain = analysis_chain | reply_prompt | llm | StrOutputParser()

result = full_chain.invoke({
    'text': '你们的发货速度太慢了，说好三天到，结果等了一周，非常失望！'
})
print(result)
```

### 代码解释

| 步骤 | 说明 |
| --- | --- |
| `analysis_chain` | 并行执行三个分析任务，输出字典 |
| `reply_prompt` | 把原始输入和分析结果一起填充到回复模板 |
| `llm \| StrOutputParser()` | 生成最终回复建议 |

注意：`reply_prompt` 中既用到了原始输入 `{text}`，也用到了并行分析结果 `{sentiment}`、`{category}`、`{summary}`。
