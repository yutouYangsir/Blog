# 07 输出解析器

## 学习目标
1. 理解输出解析器（Output Parsers）在 LangChain 链中的作用
2. 掌握常见解析器的用法：StrOutputParser、JsonOutputParser、PydanticOutputParser、CommaSeparatedListOutputParser
3. 学会使用 `手动 try-except + LLM 修复` 处理模型输出格式异常
4. 了解如何编写自定义输出解析器
5. 理解「Prompt 中说明格式 + 解析器约束」配合的重要性

## 1. 为什么需要输出解析器

大模型返回的通常是**自由文本**，但很多时候我们需要：

- 提取结构化的 JSON 数据
- 把文本转换成 Python 列表、字典或对象
- 验证输出是否符合预期的数据格式
- 过滤掉模型多余的解释，只保留关键信息

**输出解析器**就是链中负责把模型输出转换为结构化数据的组件。

在 LCEL 中，链的常见结构是：

```
chain = prompt | llm | output_parser
```

其中 `output_parser` 接收 `AIMessage` 对象，输出我们需要的 Python 数据结构。

## 2. StrOutputParser：最简单的字符串解析器

`StrOutputParser` 会把模型返回的 `AIMessage` 对象直接转换成纯字符串。

它适合的场景：
- 只需要文本回答
- 不想每次手动写 `.content`
- 作为链的最后一步统一输出类型

```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from dotenv import load_dotenv

load_dotenv()


# 创建模型
llm = ChatOpenAI(model='qwen3.6-35b-A3b', temperature=0.7)

# 创建 Prompt 模板
prompt = ChatPromptTemplate.from_messages([
    ('system', '你是一个简洁的助手。'),
    ('user', '用一句话介绍{topic}')
])

# 构建链：prompt -> llm -> 字符串解析器
chain = prompt | llm | StrOutputParser()

# 调用链，直接得到字符串
result = chain.invoke({'topic': '机器学习'})

print('返回类型：', type(result))
print('返回内容：', result)
```

### 代码解释

| 代码 | 作用 |
| --- | --- |
| `prompt \| llm \| StrOutputParser()` | 用管道符串联三个组件 |
| `StrOutputParser()` | 自动提取 `.content` 并返回字符串 |
| `type(result)` | 验证返回结果是否为 `str` |

不加 `StrOutputParser()` 时，`chain.invoke()` 返回的是 `AIMessage` 对象；加了之后返回的是 `str`。

## 3. JsonOutputParser：解析 JSON 输出

`JsonOutputParser` 会自动把模型输出的 JSON 字符串解析成 Python 字典。

使用要点：
1. 在 Prompt 中明确要求模型输出 JSON
2. JSON 中的大括号 `{` 在 Prompt 模板中需要写成 `{{` 进行转义
3. 模型输出必须能被 `json.loads()` 解析

```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import JsonOutputParser

llm = ChatOpenAI(model='qwen3.6-35b-A3b', temperature=0.1)

# 注意：模板中的 {{ 和 }} 会被 LangChain 渲染成单个 { 和 }
system_template = '''你是一个信息提取助手。请只输出 JSON 格式，不要包含任何解释。

输出格式如下：
{{\n
  "names": [...],\n
  "locations": [...],\n
  "time": ""\n
}}'''

prompt = ChatPromptTemplate.from_messages([
    ('system', system_template),
    ('user', '文本：{text}')
])

chain = prompt | llm | JsonOutputParser()

result = chain.invoke({
    'text': '2024年5月1日，李明和王芳一起去了北京故宫参观。'
})

print('返回类型：', type(result))
print('返回内容：', result)
```

### 代码解释

- `system_template` 中的 `{{` 和 `}}` 是**LangChain 模板转义语法**，表示最终 Prompt 中显示为单个 `{` 和 `}`
- `JsonOutputParser()` 会调用 `json.loads()` 解析模型输出
- 如果模型输出不是合法 JSON，会抛出异常

返回类型是 `dict`，可以直接像 `result['names']` 这样访问字段。

## 4. PydanticOutputParser：解析为 Pydantic 对象

如果你需要更严格的类型校验和结构化数据，可以使用 `PydanticOutputParser`。

Pydantic 是 Python 中非常流行的数据验证库。通过定义数据模型，可以：
- 明确每个字段的类型
- 自动验证数据格式
- 把模型输出转换成可操作的 Python 对象

```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import PydanticOutputParser
from pydantic import BaseModel, Field

llm = ChatOpenAI(model='qwen3.6-35b-A3b', temperature=0.1)

# 第一步：定义 Pydantic 数据模型
class PersonInfo(BaseModel):
    name: str = Field(description='人物姓名')
    age: int = Field(description='人物年龄')
    city: str = Field(description='所在城市')
    hobbies: list[str] = Field(description='兴趣爱好列表')

# 第二步：创建解析器
parser = PydanticOutputParser(pydantic_object=PersonInfo)

# 第三步：在 Prompt 中嵌入格式说明
prompt = ChatPromptTemplate.from_messages([
    ('system', '''你是一个信息提取助手。请从文本中提取人物信息，按指定格式输出。\n
{format_instructions}'''),
    ('user', '文本：{text}')
])

# format_instructions 会自动生成 JSON Schema 说明
prompt_with_format = prompt.partial(format_instructions=parser.get_format_instructions())

# 构建链
chain = prompt_with_format | llm | parser

result = chain.invoke({
    'text': '张三今年25岁，住在杭州，喜欢打篮球和编程。'
})

print('返回类型：', type(result))
print('返回对象：', result)
print('姓名：', result.name)
print('年龄：', result.age)
```

### 代码解释

| 步骤 | 代码 | 说明 |
| --- | --- | --- |
| 1 | `class PersonInfo(BaseModel)` | 定义数据结构，每个字段都有类型和描述 |
| 2 | `PydanticOutputParser(pydantic_object=PersonInfo)` | 创建解析器，指定要解析的模型 |
| 3 | `parser.get_format_instructions()` | 自动生成格式说明，告诉模型如何输出 |
| 4 | `prompt.partial(format_instructions=...)` | 把格式说明预先填充到 Prompt 中 |
| 5 | `chain.invoke(...)` | 返回的是 `PersonInfo` 对象 |

Pydantic 会自动校验类型，比如 `age` 必须是整数，否则报错。

## 5. CommaSeparatedListOutputParser：解析逗号分隔列表

当你需要模型返回一个列表时，可以使用 `CommaSeparatedListOutputParser`。

它适合的场景：
- 提取关键词
- 生成待办事项
- 输出多个选项

```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import CommaSeparatedListOutputParser

llm = ChatOpenAI(model='qwen3.6-35b-A3b', temperature=0.7)

# 创建解析器
parser = CommaSeparatedListOutputParser()

# 获取格式说明
format_instructions = parser.get_format_instructions()

prompt = ChatPromptTemplate.from_messages([
    ('system', '你是一个关键词提取助手。{format_instructions}'),
    ('user', '请从以下文本中提取3-5个关键词：{text}')
])

# 预填充格式说明
prompt_with_format = prompt.partial(format_instructions=format_instructions)

chain = prompt_with_format | llm | parser

result = chain.invoke({
    'text': '人工智能、机器学习和深度学习正在改变各个行业的运作方式。'
})

print('返回类型：', type(result))
print('关键词列表：', result)
print('第一个关键词：', result[0])
```

### 代码解释

- `CommaSeparatedListOutputParser()` 会自动生成格式说明：「用逗号分隔各项，不要带编号和多余解释」
- `parser.get_format_instructions()` 返回一段英文说明文本
- 返回结果是 Python 列表 `list[str]`
- 可以直接用索引访问，比如 `result[0]`

## 6. 处理格式异常：手动 try-except + LLM 修复

大模型有时不会严格按 JSON 格式输出，可能包含多余文字、缺失引号或注释。

`手动 try-except + LLM 修复` 可以包装另一个解析器，当第一次解析失败时，自动调用 LLM 修复输出格式。

```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import JsonOutputParser
import json

llm = ChatOpenAI(model='qwen3.6-35b-A3b', temperature=0.1)

# 定义一个 JSON 解析器
parser = JsonOutputParser()

# 提示模型输出 JSON，但不强制约束格式
prompt = ChatPromptTemplate.from_messages([
    ('system', '请把用户信息转换成 JSON 格式输出。'),
    ('user', '内容：{text}')
])

# 先获取模型的原始文本输出
raw_chain = prompt | llm
raw_output = raw_chain.invoke({'text': '姓名：李四，年龄：30，城市：上海'})

print('===== 原始模型输出 =====')
print(raw_output.content)

# 尝试解析 JSON
try:
    result = parser.invoke(raw_output)
    print('\n===== 直接解析成功 =====')
    print(result)
except Exception as e:
    print('\n===== 解析失败，尝试用 LLM 修复 =====')
    print('错误信息：', e)

    # 构造修复 Prompt，让模型把错误输出修正为合法 JSON
    fix_prompt = ChatPromptTemplate.from_messages([
        ('system', '你是一个 JSON 修复专家。请把用户提供的内容修正为合法 JSON，只输出 JSON 字符串，不要任何解释。'),
        ('user', '原始内容：\n{raw_output}\n\n错误信息：{error}')
    ])

    fix_chain = fix_prompt | llm
    fixed_output = fix_chain.invoke({
        'raw_output': raw_output.content,
        'error': str(e)
    })

    # 手动用 json.loads 解析修复后的内容
    result = json.loads(fixed_output.content)
    print('\n===== 修复后的结果 =====')
    print(result)
```

### 代码解释

- `手动 try-except + LLM 修复.from_llm(parser=parser, llm=llm)` 用同一个 LLM 修复格式错误
- 修复逻辑：第一次解析失败 → 把原始输出和错误信息传给 LLM → 请求模型修正为合法格式 → 再次解析
- 适合用于对稳定性要求较高的场景
- 注意：修复不一定 100% 成功，极端情况下仍会报错

## 7. 自定义输出解析器

如果内置解析器不能满足需求，你可以继承 `BaseOutputParser` 自己实现。

下面是一个简单的自定义解析器：把模型输出按指定分隔符切分成列表。

```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import BaseOutputParser

llm = ChatOpenAI(model='qwen3.6-35b-A3b', temperature=0.7)

# 自定义解析器：按换行符切分，并去除空行和序号
class NumberedListParser(BaseOutputParser[list[str]]):
    """把模型输出的编号列表解析成字符串列表。"""

    def parse(self, text: str) -> list[str]:
        # 按行切分
        lines = text.strip().split('\n')
        # 去除空行，并去掉每行开头的 1. 2. 3. 等序号
        items = []
        for line in lines:
            line = line.strip()
            if not line:
                continue
            # 去掉行首的数字和点，例如 "1. "
            if '. ' in line[:4]:
                line = line.split('. ', 1)[1]
            items.append(line)
        return items

prompt = ChatPromptTemplate.from_messages([
    ('system', '你是一个清单生成助手。请输出编号列表，每行一个项目。'),
    ('user', '请列出学习{topic}的5个步骤')
])

chain = prompt | llm | NumberedListParser()

result = chain.invoke({'topic': 'Python 编程'})

print('返回类型：', type(result))
print('返回内容：', result)
print('步骤数量：', len(result))
```

### 代码解释

- 继承 `BaseOutputParser[T]`，泛型 `T` 表示返回类型
- 必须实现 `parse(self, text: str) -> T` 方法
- `text` 是模型输出的字符串（已经过 `StrOutputParser` 提取 `.content`）
- 可以在 `parse` 中做任何字符串处理：切分、清洗、正则匹配、校验等

自定义解析器的优势是完全可控，适合处理模型输出不规范的情况。

## 8. 完整示例：结构化数据提取

下面是一个综合示例：从一段商品评价中同时提取评分、优点、缺点和关键词。

```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import PydanticOutputParser
from pydantic import BaseModel, Field

llm = ChatOpenAI(model='qwen3.6-35b-A3b', temperature=0.1)

class Review(BaseModel):
    sentiment: str = Field(description='整体情感，正面/负面/中性')
    pros: list[str] = Field(description='优点列表')
    cons: list[str] = Field(description='缺点列表')
    keywords: list[str] = Field(description='关键词列表')

parser = PydanticOutputParser(pydantic_object=Review)

prompt = ChatPromptTemplate.from_messages([
    ('system', '''你是一个商品评价分析助手。请从评价中提取结构化信息。\n
{format_instructions}\n
只输出 JSON，不要其他内容。'''),
    ('user', '商品评价：{review}')
])

prompt_with_format = prompt.partial(format_instructions=parser.get_format_instructions())

chain = prompt_with_format | llm | parser

review_text = '''这款手机外观很漂亮，拍照效果也不错。
但是电池续航一般，充电速度有点慢。
总体来说性价比还可以。'''

result = chain.invoke({'review': review_text})

print('情感：', result.sentiment)
print('优点：', result.pros)
print('缺点：', result.cons)
print('关键词：', result.keywords)
```

## 9. 常见解析器对比

| 解析器 | 返回类型 | 适用场景 |
| --- | --- | --- |
| `StrOutputParser` | `str` | 只需要文本内容 |
| `JsonOutputParser` | `dict` | 需要 JSON 字典 |
| `PydanticOutputParser` | Pydantic 对象 | 需要类型校验和结构化对象 |
| `CommaSeparatedListOutputParser` | `list[str]` | 逗号分隔的列表 |
| `手动 try-except + LLM 修复` | 依赖被包装的解析器 | 自动修复格式错误 |
| 自定义 `BaseOutputParser` | 任意类型 | 特殊格式或复杂后处理 |
