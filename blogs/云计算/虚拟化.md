# 环境准备
kvm有良好的图形化支持，所以我们可以先装一下桌面组件
1. 安装epel源并更新系统中所有的软件包
```
yum -y install epel-release
yum -y upgrade
```
2. 安装GNOME桌面软件包组
```
yum grouplist
yum groupinstall -y "GNOME Server with GUI"
```
3. 启动图形化
```
# 开机自动启动图形化
systemctl set-default graphical.target
# 启动图形化
startx &
```
# 安装KVM
```
yum install qemu-kvm libvirt virt-manager virt-install bridge-utils virt-top libguestfs-tools bridge-utils virt-viewer -y
```

# 启动服务
```
systemctl start libvirtd
systemctl enable libvirtd

# 确认已启动
[root@localhost ~]# lsmod | grep kvm
kvm_intel             442368  0
kvm                  1339392  1 kvm_intel
irqbypass              16384  1 kvm
```
