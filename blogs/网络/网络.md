## 问题
### 1. A在发送数据包的时候，怎么知道需要通过路由器呢
子网
如果源IP与目的IP在同一个子网，直接将包通过交换机发出去。
如果源IP与目的IP不在同一个子网，就交给路由器去处理。

对A来说，只要是 192.168.0.xxx开头的，就是处于同一个子网，否则就是处在不同的子网

### 2. 计算机是怎么看出来不在同一子网的
子网掩码
假如某台机器的子网掩码是255.255.255.0
将源IP与目标IP分别同这个子网掩码进行运算，相等就是在同一子网，不相等就不是
如：
```
电脑A:192.168.0.23 & 255.255.255.0 = 192.168.0.0
电脑B:192.168.0.35 & 255.255.255.0 = 192.168.0.0
电脑C:192.168.1.44 & 255.255.255.0 = 192.168.1.0
电脑D:192.168.2.55 & 255.255.255.0 = 192.168.2.0
```
对A来说，B和它就处在同一子网
C，D就处在不同子网

### 3. A 如何知道，哪台设备是路由器呢？
在A上设置默认网关
默认网关就是一个IP地址，设置默认网关，相当于告诉电脑A，不在同一子网的数据包，就发送给网关，让路由器去处理

### 4. A 怎么知道路由器的mac地址
arp
电脑内部的缓存表，记录着IP与mac地址的对应关系
一开始这个表是空的，需要经过一轮arp请求，将表中对应的数据填上

### 5. 路由器怎么把包继续往下传递呢
路由表
路由器中有个路由表

| 目标地址范围      | 端口  |
| ----------- | --- |
| 192.168.0.x | 0   |
| 192.168.1.x | 1   |
一看目标IP是192.168.1.x开头的，就把数据包从端口1发出去
在之前，路由器也需要做一轮ARP，获得C的mac地址，然后修改数据包数据链路层头部

## 如果在传输过程中数据包丢了怎么办？
A需要知道包丢了
A怎么知道？
让B告诉A
然后呢？
重传

### 停止等待协议（可靠交付）
A每发送一个包，都需要收到B的确认ACK，再发下一个包
一定时间内没有收到确认，那么就重传这个包

一个一个的发送包效率太低了
可以采用流水线发送包和ack
那问题又来了
如果A发出去的包走不同的路由，导致后发的包反而更早到，顺序就乱了

### 确认号
在发送的数据包中添加一个序号seq，同时B在响应的时候也要加入一个确认号
若B发送了一个ACK 为 3，那么不仅表示收到了3号包，也受到了1，2号包
这叫做累计确认和累计应答

### 窗口大小值
A在给B发送数据包时需要加上窗口大小值win，表示自己的接收能力
B回应时也要加上窗口大小值，表示自己的接收能力 





# 案例二

![[Pasted image 20260902074748.png]]
黑色计算机需要发送下消息给橙色计算机
他首先需要知道橙色的mac地址
发送的数据包数据链路层头部
```
源mac：BL:AC:KO 目标mac：OR:AN:GE
```
传到接口1
交换机知道了黑色计算机的mac地址在接口1，将其记录在自己的**mac地址表**中
交换机并不知道目标mac在哪个接口，于是将数据包从所有接口发了出去（这就是**泛洪**）
紫色和绿色计算机收到数据包后发现不是自己的，于是丢弃
橙色计算机收到数据包后发现是自己的，于是回应一个响应包
响应包数据链路层头部
```
源mac：OR:AN:GE 目标mac：BL:AC:KO
```
发送到交换机接口4，交换机发现橙色的mac地址在接口4，将其记录在自己的**mac地址表**中
在之后的通信中，需要发送给黑色和橙色计算机的数据包，只要网卡没有变更，就不再需要泛洪
那网卡变更了呢？那我们引入一个新的东西吧

# 案例三
![[Pasted image 20260902075749.png]]
黑色计算机需要和绿色计算机进行通信
假如我是黑色计算机
需要先知道绿色计算机的IP地址
发送数据包的头部
```
# 数据链路层头部
源mac：BL:AC:KO
目标mac：未知
# 网络层头部
源IP：192.168.0.1
目标IP：192.168.0.3
```
这个数据包将会从接口1发送给交换机
交换机泛洪，把消息发给了所有人
紫色，橙色计算机比对IP地址后，发现不是给自己的，于是丢弃
绿色计算机发现与自己的IP地址符合后
将黑色计算机的mac地址与IP地址绑定起来，以备下次使用，这就是**ARP**
然后回应黑色计算机
```
# 数据链路层头部
源mac：GR:EE:NO
目标mac：BL:AC:KO
# 网络层头部
源IP：192.168.0.3
目标IP：192.168.0.1
```
通过接口3发送给交换机，交换机比对mac地址表后，将包发送给黑色计算机
黑色计算机收到回应后
也将绿色计算机的mac地址和IP地址绑定
